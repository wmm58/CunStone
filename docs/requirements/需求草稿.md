# 篆刻印稿生成工具需求草稿

- 版本：v0.1
- 日期：2026-10-26
- 状态：需求草稿（已同步线框调整）

## 1. 产品定位

面向喜欢篆刻、但不擅长制作印稿的人，提供一个在电脑浏览器中使用的工具：

1. 用户手绘或上传一张完整图片。
2. 系统将图片处理成纯黑白、可打印、可转印的印稿。
3. 用户下载 A4、1:1 的 PDF，用于转印到石头上手工篆刻。

产品重点不是只做图片滤镜，也不是替用户设计印章，而是把用户已有的画面直接转成可进入实际篆刻流程的最终印稿。用户负责内容和构图，系统负责转稿、修整、尺寸适配和 1:1 输出。

平台不收取工具使用费，也不需要外部 AI 账号或 API Key。第一版内置基础抠图能力，可自动去除任意纯色背景（包括白色），用户可直接完成黑白稿制作和 PDF 导出。

第一版成功标准：用户可以完成制作，并成功下载 A4 PDF。打印尺寸、打印质量和镜像方向由用户自行确认，不作为系统验收条件。

## 2. 用户与使用范围

- 公开注册使用，所有注册用户均可使用。
- 使用手机号验证码登录。
- 使用设备以电脑浏览器为主，不做手机 App 或桌面安装软件。
- 用户作品保存在账号中，可再次打开继续修改。
- 不提供作品分享、公开社区或公开作品区。
- 用户无需注册或配置外部 AI 服务账号，也不需要 API Key。
- 页面必须明确说明第一版的自动抠图仅支持任意纯色背景（包括白色），复杂背景图片不在第一版保证范围内。

## 版本规划

- 不单独设置最小验收版本，第一版就是第一个交付版本。
- 后续版本只用于增加当前第一版之外的能力，不改变第一版必须完成的核心流程。

## 3. 核心页面

v0.1 只规划以下 4 个核心页面。

### 3.1 P1 登录/注册页

- 输入手机号和验证码。
- 完成注册或登录。
- 登录成功后直接进入 P2 创作编辑页。

### 3.2 P2 创作编辑页

- 是唯一的创作和编辑页面。
- 支持编辑作品名称。
- 包含印章外形、实际尺寸、上传或手绘、纯色去背景、剪影或轮廓、黑白化、编辑、阳刻/阴刻、镜像和边框。
- 不展示红印效果和黑白稿预览面板；预览统一放到 P3 作品列表的弹窗中。
- 编辑画布为主要区域，并占用页面大部分空间。
- 提供“草稿”、“保存（已完成）”和“A4 导出”三个操作按钮。
- 点击“A4 导出”进入 P4；只有已完成作品可以被添加到 A4 排版中。
- 提供返回 P3 作品列表的入口。
- 编辑状态自动保存；用户可显式保存为草稿或标记为已完成。

### 3.3 P3 作品列表页

- 导航筛选包含：全部作品、已完成、草稿。
- 作品卡片展示缩略图、作品名称、最后保存时间和状态。
- 支持新建作品，并进入 P2 创作编辑页。
- 点击作品卡片中的“预览”，以弹窗展示红印效果和黑白稿。
- 支持点击“继续编辑”返回 P2。
- 只有已完成作品可以被勾选并进入 P4。
- 在“已完成”筛选下提供“一件全选”，可一次选中当前筛选中的全部已完成作品。
- 已选作品数量显示在“一件全选”文字下方。
- 支持删除已选作品。
- 草稿可以继续编辑，但不能进入 A4 导出。

### 3.4 P4 A4 导出页

- 左侧栏标题为“已添加作品列表”。
- 左侧栏底部按钮为“添加作品”，点击后以弹窗展示已完成作品的名称和缩略图。
- 用户在弹窗中多选作品，点击确定后返回 P4，并显示总添加作品数量。
- 系统先按真实尺寸自动排版，用户可以手动调整。
- 手动排版只支持拖动位置、旋转、水平间距和垂直间距调整，不提供缩放。
- 页面放不下时自动增加 A4 页面。
- 不设置独立的“导出信息”模块，排版操作直接围绕 A4 画布进行。
- 每枚印章标注实际尺寸，并添加裁剪线。
- 下载只包含黑白稿的 PDF。

### 3.5 页面边界

- 不单独设置结果页。
- 红印效果和黑白稿只在 P3 的作品预览弹窗中展示。
- P4 只负责已完成作品的选择、排版和 PDF 下载，不承担作品编辑。

## 4. 核心制作流程

1. 用户使用手机号和验证码登录，登录成功后直接进入 P2 创作编辑页。
2. 用户编辑作品名称，选择印章外形并确认或修改实际尺寸。
3. 用户上传一张完整图片，或在画布上手绘完整构图。
4. 用户点击图片中的背景区域指定颜色，系统去除该纯色背景。
5. 用户选择实心剪影或轮廓线稿效果。
6. 系统按实际尺寸自动缩放、旋转、锐化、矫形，并适配印章外形。
7. 系统生成无灰色的纯黑白稿。
8. 用户使用画布工具修整黑白稿，并切换阳刻/阴刻、正常/左右镜像和边框。
9. 用户点击“草稿”保存为草稿，或点击“保存（已完成）”保存并标记为已完成。
10. 用户进入 P3 作品列表，可按全部作品、已完成、草稿筛选；在已完成筛选下可“一件全选”，已选数量显示在全选文字下方，并可删除已选作品。
11. 用户点击作品卡片的“预览”，通过弹窗查看红印效果和黑白稿。
12. 用户可继续编辑草稿，或选择已完成作品进入 P4。
13. 用户点击 P4 的“添加作品”，在弹窗中多选已完成作品并点击确定；返回后显示总添加作品数量。
14. 系统先自动生成 A4 初始排版，用户手动调整位置、旋转和间距。
15. 系统按 A4、1:1 生成只包含黑白稿的 PDF，用户下载。

## 5. 功能需求

### 5.1 印章外形与尺寸

- 支持正方形、长方形、圆形。
- 支持自定义长和宽。
- 系统根据外形提供默认推荐尺寸，用户可以修改。
- 所有尺寸均代表印章的实际尺寸，用于最终 1:1 输出。

### 5.2 输入方式

- 支持在网页画布上手绘。
- 支持上传本地图片。
- 支持任意纯色背景（包括白色）的图片，也支持已经画好的线稿。
- 不承诺处理背景复杂的照片；用户需要先自行处理复杂背景，再上传图片。
- 不提供键盘文字输入。
- 不自动把普通文字转换成篆书。
- 用户需要自行完成整张构图；系统不支持分别添加多个图案/文字元素后自由拼排。
- 图案和文字可以出现在同一枚印中，但必须由用户预先画好或作为一张完整图片上传。

### 5.3 图片处理

- 系统内置去背景功能，仅处理用户点击指定的纯色背景（包括白色、蓝色、绿色等），不使用外部 AI 服务。
- 系统删除与用户所选背景颜色接近的区域；主体内颜色接近的背景部分也可能被删除，需由用户后续修整。
- 用户可选择将主体处理为实心剪影或轮廓线稿。
- 系统按印章实际尺寸自动缩放、旋转、锐化、矫形和适配。
- 最终黑白稿只能包含纯黑和纯白，不能出现灰色。
- 用户可调整线条粗细。

### 5.4 黑白稿编辑

黑白稿第一版必须具备以下编辑能力：

- 画笔补黑。
- 橡皮擦除。
- 撤销和重做。
- 局部放大。
- 调整线条粗细。

### 5.5 可刻性判断

- 第一版不提供自动可刻性检查。
- 不自动提示线条过细、粘连或杂点。
- 用户通过编辑画布和 A4 导出页的 1:1 预览自行判断是否适合篆刻。

### 5.6 阳刻、阴刻与镜像

- 用户可切换阳刻或阴刻。
- 用户可在制作过程中切换正常方向或左右镜像。
- 保存时只保留用户最终确认的版本，不额外保存另一方向。
- 下载 PDF 时只输出最终确认的版本。

### 5.7 边框

- 用户可选择系统提供的边框样式。
- 用户可以上传或绘制自带边框的完整图片。
- 用户可以选择完全不要边框。
- 边框必须同时出现在线上红印效果和最终黑白 PDF 中。

### 5.8 预览、命名与保存

- P3 作品列表中的作品卡片提供“预览”入口。
- 点击“预览”后，通过弹窗同时展示红印效果和黑白印稿。
- P3 的“已完成”筛选支持“一件全选”，已选数量显示在全选文字下方。
- 支持删除 P3 中已选中的作品。
- P2 创作编辑页不展示红印和黑白稿预览面板。
- 红印效果使用干净的纯红色，不模拟纸张、印泥浓淡或边缘纹理。
- 红印效果仅用于线上展示，不进入最终 PDF。
- 作品名称可编辑。
- 编辑状态自动保存到用户账号。
- P2 提供“草稿”、“保存（已完成）”和“A4 导出”按钮。
- 点击“草稿”保存为草稿；点击“保存（已完成）”保存并标记为已完成。
- 只有已完成作品可以进入 A4 导出；草稿可继续编辑但不能进入导出。
- 作品可重新打开，并恢复到最后一次保存状态。
- 保存内容包括可继续编辑的作品状态和最终确认稿。

### 5.9 A4 排版与 PDF 下载

- 用户只能在 P4 多选添加已完成作品。
- P4 左侧展示“已添加作品列表”，底部提供“添加作品”按钮。
- 点击“添加作品”后，弹窗展示已完成作品的名称和缩略图，用户可多选。
- 点击弹窗中的“确定”返回 P4，并显示总添加作品数量。
- 系统先按真实尺寸自动生成初始排版。
- 用户可以手动拖动位置，并调整旋转、水平间距和垂直间距；不提供缩放。
- 不设置独立的“导出信息”模块，排版操作直接围绕 A4 画布进行。
- 当前 A4 页面放不下时，自动增加页面。
- 所有印章按实际尺寸 1:1 摆放。
- PDF 中每枚印章需要标注实际尺寸，并添加裁剪线。
- 用户可以只导出单枚作品，也可以导出多枚作品。
- PDF 只包含黑白稿，不包含红印效果。
- 导出时的作品选择、手动位置和间距属于当前导出会话，不作为作品数据长期保存。
- PDF 即时生成，不保存历史文件。

## 6. 关键输出规则

- 黑白稿中，黑色代表保留的石头部分，白色代表需要刻掉的部分。
- 切换阳刻/阴刻时，系统按上述黑白约定重新生成对应稿面。
- PDF 只包含最终确认的黑白稿，不包含红印效果。
- PDF 中必须包含边框、尺寸标注和裁剪线。
- 每枚印章必须按实际尺寸 1:1 输出。
- 镜像方向以用户保存前最后确认的版本为准。
- 只有标记为“已完成”的作品可以进入 A4 导出。

## 7. 第一版默认建议

- A4 默认纵向。
- 常用尺寸推荐：
  - 方章：20 mm、25 mm、30 mm。
  - 长方章：15×30 mm、20×30 mm。
  - 圆章：直径 20 mm、25 mm、30 mm。
- 边框至少提供：无边框、单线、粗线、双线、残破边。
- 自动去背景只针对任意纯色背景；背景复杂或主体与背景颜色接近时，系统不保证自动处理结果。

## 8. 第一版不做

- 不做键盘文字输入。
- 不自动生成或转换篆书文字。
- 不支持在系统内分别添加多个元素并自由拼排。
- 不做真实红印质感。
- 不做作品分享、社区或公开作品区。
- 不做手机 App。
- 不做桌面安装软件。
- 不向用户收取平台工具费。
- 不提供复杂背景照片的一键抠图能力。
- 不自动识别背景颜色，也不处理渐变、多色或复杂背景，背景颜色由用户点击指定。
- 不接入外部 AI 抠图服务，也不需要用户配置 API Key。
- 不单独设置结果页。
- 不在 P2 创作编辑页展示红印或黑白稿预览面板。

## 9. 风险与待确认事项

- 背景色与主体颜色接近时，自动去背景可能误删主体或残留背景，需要依赖手动修整。
- 需要确定用户点选背景后的颜色容差和边缘处理规则。
- 自动可刻性检查延后，第一版没有统一的线条过细、粘连和杂点判断标准。
- 需要确定支持的上传文件格式、文件大小和图片分辨率上限。
- 需要确定用户作品的保存期限、删除方式及账号注销后的数据处理规则。
- 公开上传场景可能需要内容审核和滥用处理机制。

- 更多边框样式和更丰富的黑白稿编辑工具。
