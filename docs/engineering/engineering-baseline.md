# CunStone v0.1 工程基线

- 日期：2026-11-08
- 状态：已确认
- 适用范围：CunStone v0.1 的页面与功能开发

本文只记录已确认的工程技术口径；产品行为仍以蓝图和对应 OpenSpec Change 为准。

## 1. 技术栈

- **构建与开发服务器**：Vite
- **界面框架**：React
- **开发语言**：TypeScript
- **样式方案**：Tailwind CSS
- **PDF 生成**：`pdf-lib`，在浏览器本地执行
- **测试**：Vitest + Testing Library，当前统一通过 `npm test` 运行

## 2. 数据保存

v0.1 使用浏览器 **localStorage** 作为唯一应用数据持久化方式，命名空间为 `cunstone:v0.1:app-state`。

### 2.1 当前数据结构

- 当前结构版本为 **v7**。
- 用户账号、活动本地账号、作品名称、状态、时间和所属用户保存在同一根状态对象中。
- 作品图片状态保存 `sourceKind`、`sourceDataUrl`、外形、宽高、背景颜色规则、效果类型、1–8 级轮廓粗细、0–8 锐化、0–20 mm 外边距、1–80 图片橡皮大小和 `processingVersion: 5`。
- 每条背景规则保存 `id`、可空颜色和 0–100 容差；规则总数最多 10 条。
- 黑白状态保存压缩覆盖层、画笔大小、橡皮大小、阴阳刻、方向、无/单线/双线边框、1–8 级边框粗细、0–20 mm 边框外边距和 `editVersion: 4`；历史残破边仅用于兼容读取。
- 不保存最终黑白 PNG、撤销/重做历史、PDF 文件或导出历史。

### 2.2 存储边界

- 数据只保存在当前浏览器和当前域名下。
- 不支持跨浏览器、跨设备或跨浏览器配置同步。
- 清除浏览器站点数据、使用无痕模式或更换设备会导致数据不可用。
- 不将真实短信凭据、支付信息、身份证明或其他敏感密钥写入 localStorage。
- localStorage 中的数据不是安全边界，不能作为生产级身份认证或权限控制依据。
- PDF 仅在用户点击下载时即时生成，不写入 localStorage，不保留导出历史。

### 2.3 写入与恢复

- 应用数据必须通过统一存储适配层读写。
- 有可打印黑色内容时才允许自动保存或显式保存；空白作品不能创建或覆盖作品记录。
- 图片橡皮和裁剪产生的工作图只在当前会话累积，不逐笔自动保存；显式点击“草稿”“保存”或“A4 导出”时才使用最新工作图持久化。
- 清除画布后，最后一次有效保存版本保留在 localStorage，直到用户重新产生有效内容并保存。
- 读取到损坏或不兼容数据时使用空状态启动并显示恢复提示，不让页面崩溃。

## 3. v7 迁移口径

- v1：补齐默认图片状态和默认黑白状态。
- v2：把旧单背景 `backgroundColor + tolerance` 迁移为 0 或 1 条背景规则，并补齐默认黑白状态。
- v3：迁移单背景规则，保留手绘来源和残破边，补充轮廓粗细 1、`borderThickness` 和 `editVersion: 2`。
- v4：补齐 `outlineThickness: 1`、`processingVersion: 3`，并把历史粗线换算为等效单线粗细。
- v5：补齐锐化 1、外边距 0、图片橡皮 24、手绘橡皮 6，并升级处理/编辑版本。
- v6：把百分比外边距按作品短边换算为 0.1 mm 精度，边框外边距补 0，`processingVersion` 升为 5、`editVersion` 升为 4。
- 旧 `shape: "custom"` 迁移为等宽 `square` 或不等宽 `rectangle`，宽高不变。
- 旧 `sourceKind: "drawing"`、历史粗线和 `borderStyle: "broken"` 保留兼容读取，不提供新建入口。
- 有手动覆盖层的 v3/v4/v5/v6 作品迁移时必须按 v7 图片状态重算 `generationSignature`，保留覆盖层内容和尺寸。
- 迁移后的数据在读取时先保留在内存中，应用启动成功后以 v7 写回；写回失败不得丢失当前内存迁移结果。

## 4. 回滚限制

- v0.1.6 旧代码会把 v4/v5/v6/v7 数据识别为不支持版本，不能直接读取升级后的 localStorage。
- 回滚运行旧代码前，应使用固定的 v3 测试副本恢复数据，不能直接把 v4/v5/v6/v7 数据当 v3 覆盖。
- 若 v0.1.7 验收发现问题，不覆盖已占用版本；按项目版本规则创建下一个 PATCH。

## 5. 基线验收

- 项目使用 Vite + React + TypeScript + Tailwind CSS 运行。
- v1–v6 固定样本均可迁移到 v7，且账号、作品、轮廓/锐化/mm 外边距/工具默认值和最后有效编辑结果不丢失。
- 多背景规则最多 10 条，每条独立容差并按并集去除。
- 历史手绘、旧 custom 和旧 broken 作品可打开、预览和导出。
- 轮廓与边框粗细在 P2、P3 预览与 PDF 中一致；历史粗线迁移后仍可见。
- 图片裁剪、透视裁剪和图片橡皮可连续应用并在显式保存时持久化；背景规则在图片编辑后保留。
- 手绘画笔与橡皮大小分别恢复；图片和黑白稿编辑始终可双向切换。
- 锐化与 mm 外边距可调，0 mm 时内容最短边贴齐印章边界；边框 mm 外边距跨 P2/P3/P4/PDF 一致。
- 草稿可多选删除，P4 下载按钮位于顶部工具栏。
- 清除画布不会覆盖最后一次有效保存。
- 应用不依赖服务端数据库或云同步即可完成 v0.1 本地数据闭环。
