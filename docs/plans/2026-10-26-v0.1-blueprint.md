## 1. 版本目标

### 1.1 产品定义

CunStone v0.1 是一个面向篆刻爱好者的电脑浏览器工具。

用户提供一张已经完成的画面，系统将其处理成纯黑白、可打印、可转印的印稿，并支持用户下载 A4、1:1 的 PDF，用于转印到石头上手工篆刻。

产品不负责设计画面、不替用户排列图案与文字，也不生成篆书。

### 1.2 v0.1 要达成的结果

- 用户可以使用手机号和固定测试验证码注册并登录；真实短信留到后续版本接入。
- 登录成功后直接进入 P2 创作编辑页。
- 用户可以新建并保存作品，下次登录后继续编辑。
- 用户可以编辑作品名称，并按需保存为草稿或已完成。
- 用户可以上传图片，或在画布上手绘完整构图。
- 用户可以点击纯色背景，让系统自动去除该背景颜色。
- 系统可以将画面处理成无灰色的黑白稿，并允许用户手动修整。
- 用户可以选择印章外形、实际尺寸、阳刻/阴刻、左右镜像和边框。
- 用户可以在 P3 作品列表通过弹窗查看红印效果与黑白稿。
- 用户可以在 P4 通过弹窗多选已完成作品，查看总添加数量，手动调整排版，并下载 PDF。

### 1.3 版本原则

- 第一版就是第一个正式交付版本，不另设最小验收版本。
- 平台免费使用，不接入外部 AI 服务，不需要用户提供 API Key。
- 只有标记为“已完成”的作品可以进入 A4 导出；草稿不能导出。
- 不设置独立结果页，红印和黑白稿预览在 P3 的作品弹窗中展示。
- 真实打印与雕刻效果不由系统验收，由用户自行确认。

## 2. 用户与权限

### 2.1 用户范围

- 面向公开注册的所有用户。
- 用户主要在电脑浏览器中使用。
- 第一版不提供手机 App 和桌面安装程序。

### 2.2 账号规则

- v0.1 使用手机号和固定测试验证码登录；真实短信通道留到后续版本接入。
- 未登录用户只能访问登录/注册页面。
- 登录用户可以创建、查看、编辑、保存和导出自己的作品。
- 作品自动保存编辑状态。
- 用户只能访问自己的作品。

### 2.3 权限边界

- 不提供作品分享、公开社区或公开作品区。
- 不提供访问其他用户作品的入口。

## 3. 核心页面

v0.1 只规划以下 4 个核心页面。

### 3.1 P1 登录/注册页

- 输入手机号并获取验证码。
- v0.1 使用固定测试验证码完成注册或登录，真实短信后续接入。
- 登录成功后直接进入 P2 创作编辑页。

### 3.2 P2 创作编辑页

该页面是唯一的创作与编辑页面，包含：

- 可编辑的作品名称。
- 印章外形和实际尺寸设置。
- 上传图片入口和手绘画布。
- 点击背景颜色并去除纯色背景，提供背景颜色容差滑杆。
- 实心剪影或轮廓线稿选择。
- 自动缩放、旋转、锐化、矫形和外形适配。
- 纯黑白转换。
- 画笔、橡皮、撤销重做、局部放大和线宽调整。
- 阳刻/阴刻、正常/左右镜像和边框设置。
- 自动保存当前编辑状态。
- 返回 P3 作品列表的入口。
- “草稿”、“保存（已完成）”和“A4 导出”三个操作按钮。
- 点击“A4 导出”进入 P4；只有已完成作品可以被添加到 A4 排版中。

编辑画布是该页面的主要区域，占用页面大部分空间。

该页面不展示红印效果和黑白稿预览面板。预览统一在 P3 的作品预览弹窗中展示。

### 3.3 P3 作品列表页

- 导航筛选包含：全部作品、已完成、草稿。
- 显示作品缩略图、作品名称、最后保存时间和状态。
- 点击“预览”打开弹窗，同时展示红印效果和黑白稿。
- 支持新建作品，进入 P2。
- 支持打开草稿继续编辑，返回 P2。
- 只有已完成作品可以被勾选并进入 P4。
- 在“已完成”筛选下提供“一件全选”，可一次选中当前筛选中的全部已完成作品。
- 已选作品数量显示在“一件全选”文字下方。
- 支持删除已选作品；删除前需要二次确认，确认后永久删除。
- 草稿可以继续编辑，但不能进入 A4 导出。

### 3.4 P4 A4 导出页

- 左侧栏标题为“已添加作品列表”。
- 左侧栏底部按钮为“添加作品”，点击后以弹窗展示已完成作品的名称和缩略图。
- 用户在弹窗中多选作品，点击确定后返回 P4，并显示总添加作品数量。
- 按真实尺寸自动生成初始排版。
- 支持手动调整排版，只包括拖动位置、旋转、水平间距和垂直间距，不提供缩放。
- 展示页数和排版结果。
- 当前页放不下时自动增加页面。
- 不设置独立的“导出信息”模块，排版操作直接围绕 A4 画布进行。
- 每枚印章标注实际尺寸并添加裁剪线。
- 生成并下载只包含黑白稿的 PDF。

### 3.5 页面边界

- 不单独设置结果页。
- 红印效果和黑白稿仅在 P3 的作品预览弹窗中展示。
- P4 负责已完成作品的多选、手动排版和 PDF 下载，不承担作品编辑。

## 4. 数据对象

v0.1 只有两个持久数据对象：用户和作品。PDF 属于即时生成结果，不单独存档。

### 4.1 用户

- 用户标识。
- 登录手机号。
- 注册时间。

### 4.2 作品

- 作品标识。
- 所属用户标识。
- 作品名称。
- 原图或手绘画布内容。
- 用户点击选定的背景颜色及去背景结果。
- 印章外形。
- 实际宽度和高度。
- 剪影/轮廓线稿选择。
- 当前黑白稿编辑状态。
- 线条粗细设置。
- 阳刻/阴刻选择。
- 正常/左右镜像方向。
- 边框选择。
- 作品状态：草稿或已完成。
- 创建时间和最后保存时间。

### 4.3 非持久对象

- 红印预览和黑白预览属于展示结果，不作为独立业务对象。
- 多选导出时选择的临时作品集合，以及 P4 中的手动排版位置和间距，不作为长期数据保存。
- PDF 每次按作品当前最后保存状态即时生成，不保存历史文件。
- 第一版不保存导出记录。

## 5. 功能范围

### 5.1 第一版必须提供

#### 账号与作品

- 手机号注册和登录；v0.1 使用固定测试验证码，真实短信后续接入。
- 登录成功后直接进入 P2 创作编辑页。
- 新建作品。
- 编辑作品名称。
- 自动保存编辑状态。
- 从作品列表继续编辑。
- 作品仅归当前登录用户所有。
- 作品状态包含草稿和已完成。
- 用户可通过“草稿”保存为草稿，通过“保存（已完成）”保存并标记为已完成。
- 只有已完成作品可以进入 A4 导出。
- P3 的“已完成”筛选支持“一件全选”，已选数量显示在全选文字下方。
- P3 支持删除已选作品；删除前二次确认，确认后永久删除。

#### 输入与抠图

- 上传本地图片。
- 在网页画布上手绘完整构图。
- 上传或手绘内容必须由用户预先完成，不支持在系统内拼排多个独立元素。
- 用户点击图片中的背景区域指定颜色。
- 系统删除与所选颜色接近的纯色背景。
- 提供背景颜色容差滑杆，用于调整纯色背景的去除范围。
- 支持任意纯色背景，包括白色、蓝色和绿色。
- 不处理渐变、多色或复杂背景。
- 背景残留或误删由用户使用橡皮、画笔等编辑工具修整。

#### 图片处理

- 选择实心剪影或轮廓线稿效果。
- 按印章实际尺寸自动缩放、旋转、锐化和矫形。
- 适配正方形、长方形、圆形和自定义长宽。
- 转换为纯黑和纯白，不出现灰色。
- 调整线条粗细。

#### 黑白稿编辑

- 画笔画黑。
- 橡皮擦除。
- 撤销和重做。
- 局部放大。
- 调整线条粗细。

#### 预览、阴阳刻与边框

- P3 作品卡片提供“预览”入口，通过弹窗同时展示红印效果和黑白稿。
- P2 创作编辑页不展示红印和黑白稿预览面板。
- 红印使用干净的纯红色，不模拟纸张、印泥浓淡和边缘纹理。
- 红印效果不进入 PDF。
- 切换阳刻和阴刻。
- 切换正常方向和左右镜像。
- 保存时只保留用户最后确认的方向。
- 选择系统边框、使用原图自带边框或不要边框。
- 边框同时反映在红印预览和黑白 PDF 中。

#### A4 排版与 PDF

- P4 左侧展示“已添加作品列表”，底部提供“添加作品”按钮。
- 点击“添加作品”后，弹窗展示已完成作品的名称和缩略图，用户可多选。
- 点击弹窗中的“确定”返回 P4，并显示总添加作品数量。
- 系统先按真实尺寸生成初始排版。
- 用户可以手动拖动位置，并调整旋转、水平间距和垂直间距；不提供缩放。
- 不设置独立的“导出信息”模块，排版操作直接围绕 A4 画布进行。
- 按真实尺寸 1:1 放置。
- 自动留出印章间距。
- 页面放不下时自动增加 A4 页面。
- 每枚印章标注实际尺寸。
- 每枚印章添加裁剪线。
- 单枚和多枚均可导出。
- PDF 只包含最终保存的黑白稿，不包含红印效果。

### 5.2 默认规则

- A4 默认纵向。
- 方章推荐尺寸：20 mm、25 mm、30 mm。
- 长方章推荐尺寸：15×30 mm、20×30 mm。
- 圆章推荐直径：20 mm、25 mm、30 mm。
- 系统提供尺寸推荐，用户可自行修改。
- 边框至少提供：无边框、单线、粗线、双线、残破边。
- 黑白稿中，黑色代表保留的石头部分，白色代表需要刻掉的部分。

### 5.3 延后到后续版本

- 自动可刻性检查，包括线条过细、粘连和杂点提醒。
- 复杂背景照片的自动抠图。
- 系统自动识别纯色背景，无需用户点选。
- 更丰富的边框和黑白稿编辑工具。
- 自动把文字转换为篆书。
- 作品分享、社区、手机端和真实印泥质感。

### 5.4 第一版明确不做

- 不做印章设计。
- 不做键盘文字输入。
- 不自动生成或转换篆书文字。
- 不支持在系统内分别添加多个元素并自由拼排。
- 不接入外部 AI 服务。
- 不要求用户配置外部账号或 API Key。
- 不处理复杂背景、多色背景或渐变背景。
- 不自动检查是否适合篆刻。
- 不验证真实打印尺寸、打印质量或雕刻结果。
- 不保存 PDF 历史文件或导出记录。
- 不单独设置结果页。
- 不在 P2 创作编辑页展示红印或黑白稿预览面板。
- 不提供分享、社区、手机 App 或桌面软件。

## 6. 核心流程

1. 用户使用手机号和验证码登录；首次使用时完成注册。
2. 用户登录后直接进入 P2 创作编辑页；如需继续已有作品，可从 P2 进入 P3。
3. 用户编辑作品名称，选择印章外形，确认或修改实际尺寸。
4. 用户上传一张完整图片，或在画布上手绘完整构图。
5. 用户点击图片中的背景区域，调节背景颜色容差，系统去除对应的纯色背景。
6. 用户选择实心剪影或轮廓线稿效果。
7. 系统按实际尺寸缩放、旋转、锐化、矫形，并适配印章外形。
8. 系统生成无灰色的纯黑白稿。
9. 用户使用画笔、橡皮、撤销重做、局部放大和线宽调整修整黑白稿。
10. 用户切换阳刻/阴刻、正常/左右镜像，并选择边框。
11. 系统自动保存编辑状态；用户可点击“草稿”保存为草稿，或点击“保存（已完成）”标记为已完成。
12. 用户进入 P3 作品列表，可以按全部作品、已完成、草稿筛选；在已完成筛选下可“一件全选”，已选数量显示在全选文字下方，并可经二次确认永久删除已选作品。
13. 用户点击作品卡片的“预览”，通过弹窗查看红印效果和黑白稿；需要修改时返回 P2 继续编辑。
14. 用户点击 P4 的“添加作品”，在弹窗中多选已完成作品并点击确定；返回后显示总添加作品数量。
15. 系统先自动生成 A4 初始排版，用户手动调整印章位置、旋转和间距。
16. 用户确认排版结果，下载 A4、1:1、只包含黑白稿的 PDF。

## 7. 验收标准

### 7.1 验收方式

- 使用固定验收样本走通完整流程。
- 固定样本至少覆盖一张纯色背景的上传图片和一份画布手绘稿。
- 验收从注册/登录开始，到成功下载 PDF 结束。
- 不验证真实打印机输出、转印效果或雕刻结果。

### 7.2 必须通过的验收项

1. 用户可以使用手机号和固定测试验证码完成注册和登录，并直接进入 P2 创作编辑页；真实短信不纳入 v0.1 验收。
2. 未登录用户不能访问作品和编辑功能。
3. 用户可以新建作品，并只能看到自己的作品。
4. 用户可以编辑作品名称。
5. 用户可以选择正方形、长方形、圆形和自定义长宽。
6. 用户可以确认或修改印章实际尺寸。
7. 用户可以上传固定样本图片，也可以完成固定样本手绘稿。
8. 用户可以点击背景指定颜色，调节背景颜色容差滑杆并去除对应的纯色背景，可以选择实心剪影或轮廓线稿效果，并可用橡皮修整残留边缘。
9. 系统可以生成无灰色的纯黑白稿。
10. 用户可以在黑白稿上使用画笔、橡皮、撤销重做、局部放大和线宽调整。
11. 用户可以切换阳刻/阴刻、正常/左右镜像和边框。
12. 编辑状态自动保存；用户可以保存为草稿或保存为已完成，并能恢复到最后保存状态。
13. P3 作品列表支持全部作品、已完成和草稿三种筛选，其中“已完成”筛选支持“一件全选”，已选数量显示在全选文字下方。
14. P3 作品卡片的预览弹窗同时展示红印效果和黑白稿。
15. P3 支持删除已选中的作品；删除前出现二次确认，确认后永久删除。
16. 只有已完成作品可以进入 P4；草稿不能导出。
17. P4 左侧标题为“已添加作品列表”，底部按钮为“添加作品”。
18. 点击“添加作品”后，弹窗展示已完成作品的名称和缩略图，支持多选；确定后返回 P4 并显示总添加作品数量。
19. P4 只支持手动拖动、旋转和调整间距，不提供缩放。
20. 下载的 PDF 可以正常打开，页面尺寸为 A4。
21. PDF 中每枚印章的实际尺寸与作品设置一致，并按 1:1 排版。
22. PDF 中包含选中边框、每枚印章的尺寸标注和裁剪线。
23. PDF 只包含黑白稿，不包含红印效果。
24. 全程不要求外部 AI 账号或 API Key。
25. 系统不显示自动可刻性检查结果，用户通过预览自行判断。

### 7.3 不作为 v0.1 验收条件

- 实际打印出来的尺寸是否被打印机缩放。
- 打印后的清晰度和纸张效果。
- 转印到石头后的效果。
- 实际雕刻结果。
- 复杂背景照片的自动抠图效果。
- 自动可刻性提醒的准确性。

## 8. 版本完成定义

当固定样本从注册/登录直接进入 P2、创建并命名作品、上传或手绘、纯色去背景、黑白化、编辑、保存为草稿或已完成、在 P3 筛选、全选、删除和预览、在 P4 通过弹窗多选添加已完成作品、手动排版并下载 PDF 的完整流程全部通过，且 7.2 的验收项全部成立时，CunStone v0.1 视为完成。
