# CunStone

CunStone v0.1 是一个单浏览器本地原型，用于把已有画面制作成可打印、可转印的黑白印稿。

当前实现范围是 OpenSpec Change 1：本地测试登录、账号与作品数据、草稿/已完成状态、自动保存和重新打开作品。

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS

## 本地运行

```bash
npm install
npm run dev
```

Vite 默认在 `http://localhost:5173` 启动；端口被占用时会自动使用下一个可用端口。

验证命令：

```bash
npm test
npm run typecheck
npm run build
```

## 本地测试登录

- 手机号使用 11 位中国大陆手机号格式。
- 默认固定测试验证码：`123456`
- 可以通过 `VITE_TEST_VERIFICATION_CODE` 覆盖测试验证码；示例见 `.env.example`。
- 页面上的“获取测试验证码”只填入测试验证码，不发送真实短信。
- 不调用真实短信、身份核验或支付服务。

## 页面与路由

- `#/login`：P1 登录/注册页。
- `#/editor/new`：P2 新建作品外壳。
- `#/editor/:workId`：按作品标识重新打开 P2 编辑页。
- P3 作品列表和 P4 A4 导出不在 Change 1 范围内。

## 数据与安全边界

- 所有应用数据保存在当前浏览器和当前站点的 `localStorage` 中。
- 不支持跨浏览器、跨设备或云同步。
- 清除站点数据后，本地账号和作品无法恢复。
- 本地账号只用于区分作品数据，不构成安全隔离；用户可以通过浏览器工具查看或修改 localStorage。
- 不保存敏感凭据、支付信息或真实身份资料。

## 当前范围

包含：

- 本地测试登录与账号复用
- 本地作品创建、命名、草稿/已完成保存
- 自动保存和手动保存
- 同一浏览器中的作品恢复
- 写入失败提示

不包含：

- 真实短信、身份核验和缴费
- 图片编辑、作品列表和 A4/PDF 导出
- 跨设备同步和生产级安全认证
