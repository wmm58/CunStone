# CunStone

CunStone v0.1 是一个单浏览器本地原型，用于把已有画面制作成可打印、可转印的黑白印稿。

当前实现范围是 OpenSpec Change 1–7：统一品牌头部、本地测试登录、账号与作品数据、图片上传、多背景颜色去除、纯黑白基础稿、分模式编辑、轮廓与边框粗细、作品列表、预览与管理、A4 自动排版、手动调整和 PDF 导出。

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS

## 本地运行

```bash
npm install
npm run dev
```

Vite 默认在 `http://localhost:5173` 启动；端口被占用时会自动使用下一个可用端口。

验证命令：

```bash
npm test
npm run typecheck
npm run build
```

## 本地测试登录

- 手机号使用 11 位中国大陆手机号格式。
- 默认固定测试验证码：`123456`
- 可以通过 `VITE_TEST_VERIFICATION_CODE` 覆盖测试验证码；示例见 `.env.example`。
- 页面上的“获取测试验证码”只填入测试验证码，不发送真实短信。
- 不调用真实短信、身份核验或支付服务。

## 页面与路由

- `#/login`：P1 登录/注册页。
- `#/editor/new`：P2 新建作品编辑页。
- `#/editor/:workId`：按作品标识重新打开 P2 编辑页。
- `#/works`：P3 作品列表页。
- `#/export/a4`：P4 A4 排版页。

## 品牌与页面头部

- P1–P4 使用统一的内嵌 SVG 印章 Logo、放大的 `CUNSTONE` 字标和页面名称。
- 页面不再显示 `CUNSTONE · P1/P2/P3/P4` 编号角标。
- 页面名称分别为“登录 / 注册”“创作编辑”“作品列表”“A4 导出”。

## P3 作品列表

- 支持全部作品、已完成、草稿三种筛选。
- 作品卡片显示黑白缩略图、名称、最后保存时间和状态。
- 预览弹窗同时展示纯红印效果和黑白印稿。
- 支持继续编辑和新建作品。
- 已完成筛选支持“一键全选”，已选数量显示在按钮前面并与删除、A4 导出同排。
- 支持二次确认后永久删除已选作品。
- 草稿筛选支持与已完成一致的多选、一键全选和删除，但不显示 A4 导出。
- 已完成的已选作品可以进入 P4 排版并下载 PDF。

## P4 A4 排版

- 从 P2 已完成作品或 P3 已选作品进入 P4。
- “添加作品”弹窗只展示当前账号的已完成作品，支持多选和去重。
- 左侧“已添加作品列表”显示作品、实际尺寸和总添加数量。
- 按作品实际毫米尺寸自动排版，空间不足自动生成新 A4 页面。
- 支持拖动、90° 旋转、水平间距和垂直间距调整，不提供缩放。
- 预览显示实际尺寸标注和四角裁剪线。
- “下载 PDF”位于顶部排版工具栏右侧。
- “下载 PDF”会把当前排版即时生成并下载为 A4、1:1、仅黑白稿的 PDF。

## PDF 导出

- 使用浏览器本地 `pdf-lib` 生成 PDF，不调用服务端。
- PDF 页面为 A4 纵向 210×297 mm，页数与 P4 排版一致。
- 作品按实际毫米尺寸、位置和旋转输出。
- PDF 包含纯黑白印稿、选中边框、实际尺寸文字和四角裁剪线。
- 不包含红印效果、灰色、分享内容或自动可刻性检查。
- 不保存 PDF 历史或导出记录，每次按当前排版即时生成。

## P2 图片预处理

- 支持上传 PNG、JPEG、WebP，单文件不超过 10 MB。
- 图片在本地降采样到最长边 1600 像素后处理。
- 02 只提供图片上传；空白画布中心也可打开同一图片选择器。历史手绘作品仍可打开、预览和导出，但不再提供新手绘入口。
- 模式切换位于左侧工具区顶部：“图片编辑”显示上传、去底、裁剪和图片橡皮，“黑白稿编辑”显示外形、效果、手绘和刻印边框工具；两种模式始终可双向切换，没有图片时也可进入黑白稿编辑查看空状态。
- 各工具模块使用图标代替数字序号；右侧画布占满剩余空间，默认正方形按 1:1 等比显示。
- 支持正方形、长方形、圆形实际尺寸，范围为 10–100 mm；不再提供自定义外形和推荐尺寸。
- 支持最多 10 条背景颜色规则，每条可独立取样、重新取样、调整 0–100 容差或删除；所有有效颜色按并集去除。
- 支持矩形裁剪和四点透视裁剪，应用后只保留目标区域、保留背景颜色规则并立即使用最新工作图生成黑白稿。
- 支持 1–80 px 图片橡皮，按笔画连续擦除为透明并显示大小光标；抬笔后保持橡皮工具，可继续下一笔。
- 图片橡皮和裁剪产生的工作图不会逐笔自动保存；点击“草稿”“保存”或“A4 导出”时才持久化最新工作图。
- 支持实心剪影和轮廓线稿两种纯黑白效果；轮廓线稿提供 1–8 级轮廓粗细。
- 支持 0–8 级锐化和 0–20 mm 外边距，步进 0.1 mm；0 mm 时内容最短边贴齐印章边界，外边距增大时内容按毫米缩进。
- “手绘”区支持画笔、橡皮、撤销、重做和 50%–400% 查看缩放；画笔和橡皮分别保存 1–32 px 大小。
- 画笔或橡皮操作时显示对应大小滑杆、px 数值和画布光标。
- 支持阳刻/阴刻、正常/左右镜像，以及无、单线、双线三种新边框、1–8 级边框粗细和 0–20 mm 边框外边距；历史粗线迁移为等效单线，历史残破边只读兼容。
- 手动修整保存在独立覆盖层中；撤销/重做历史只在当前编辑会话保留。
- 修改 01–04 处理参数或有效背景规则时，如已存在手动修整会先要求确认，确认后重置修整。
- 页面不常驻显示草稿、未保存或本地账号说明；保存成功通过弹窗说明结果和本地数据范围。
- 有未保存修改离开编辑页时弹窗提供继续编辑、保存草稿并继续或直接离开。
- 已有画布内容重新上传时弹窗提供取消、保存草稿并替换或直接替换。
- 空白作品不能保存为草稿或已完成；提示“作品为空”，且不会覆盖最后一次有效保存。
- 顶部“清除”会清空图片、规则、修整和历史，保留作品名称、记录、外形与尺寸。
- P2 点击 A4 导出会先自动保存为已完成，再进入 P4。
- 自动执行方向归一化、透明边裁切、等比缩放、居中、锐化和印章外形裁切。
- 透视裁剪由用户手动点选四角，不自动识别复杂照片中的透视边界。
- 不处理复杂照片、渐变或混合背景。
- 图片处理全部在浏览器本地完成，不调用自建 API、服务端或外部 AI。

## 数据与安全边界

- 所有应用数据保存在当前浏览器和当前站点的 `localStorage` 中。
- localStorage 数据结构使用 v7；打开 v1–v6 数据时会自动迁移，并在迁移时重算旧手动覆盖层的生成签名。
- v6 百分比外边距会按作品短边换算为毫米；v7 保存背景颜色规则、轮廓粗细、锐化、毫米外边距、边框外边距、图片/手绘橡皮大小、压缩黑白修整覆盖层、阴阳刻、镜像和边框，不保存最终黑白 PNG 或撤销/重做快照。
- 旧自定义外形迁移为等宽 `square` 或不等宽 `rectangle`；旧 `drawing` 来源、历史粗线和 `broken` 边框保留读取、预览与导出能力。
- 不支持跨浏览器、跨设备或云同步。
- 清除站点数据后，本地账号和作品无法恢复。
- 本地账号只用于区分作品数据，不构成安全隔离；用户可以通过浏览器工具查看或修改 localStorage。
- 不保存敏感凭据、支付信息或真实身份资料。

- 图片上传、多背景颜色规则、独立容差和外形适配

- 0–8 级锐化和 0–20 mm 外边距
- 阳刻/阴刻、左右镜像、三种新系统边框、可调边框粗细和边框外边距
- 1–8 级轮廓线粗细
- 保存成功、未保存离开和重新上传替换弹窗
- P2 自动保存为已完成后直接进入 A4
- 手动修整与印章设置的自动保存和同浏览器恢复
- P3 作品筛选、卡片、红印/黑白预览、继续编辑和永久删除
- P4 已完成作品添加、A4 自动分页、拖动、旋转和间距调整

- P3 草稿多选删除

不包含：

- 真实短信、身份核验和缴费
- 跨设备同步和生产级安全认证
- 新手绘入口、新建粗线入口和新建历史残破边入口
