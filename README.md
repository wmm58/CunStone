# CunStone

CunStone v0.1.8 是一个纯静态、单用户、单浏览器本地工具，用于把已有画面制作成可打印、可转印的黑白印稿。

打开网址即可使用：没有登录注册、没有后端、没有数据库，也不需要连接业务服务器。图片处理、localStorage 保存和 PDF 下载全部在浏览器本地完成。

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS
- `pdf-lib` 浏览器本地生成 PDF

## 本地运行

```bash
npm install
npm run dev
```

Vite 默认在 `http://localhost:5173` 启动；端口被占用时会自动使用下一个可用端口。

完整验证：

```bash
npm test
npm run typecheck
npm run build
```

`npm run build` 会生成 `dist/`，并执行静态运行时检查，确认构建资源使用相对路径且不包含业务 API 或外部 AI 地址。

## Gitee Pages 部署

1. 运行 `npm install`。
2. 运行 `npm run build`。
3. 将 `dist/` 中的静态文件发布到 Gitee Pages 指定的仓库或分支目录。
4. 使用 Gitee Pages 项目地址打开 `index.html`。

应用使用相对资源路径和 Hash 路由，适用于 Gitee Pages 的项目子路径。`#/editor/new`、`#/works` 和 `#/export/a4` 刷新时不需要服务器路由重写。

## 页面与路由

- `#/editor/new`：创作编辑页，新建作品。空 Hash、根路径和旧 `#/login` 也会进入这里。
- `#/editor/:workId`：打开当前浏览器中的已有作品。
- `#/works`：作品列表页。
- `#/export/a4`：A4 排版与 PDF 下载页。

产品只有创作编辑、作品列表和 A4 导出三个核心页面。旧登录入口仅作为历史书签兼容跳转，不显示登录表单。

## 单用户本地数据

- 所有作品保存在当前浏览器和当前站点的 localStorage 中，存储键为 `cunstone:v0.1:app-state`。
- 当前数据结构为单用户 v8：`{ version: 8, works: [...] }`，不包含用户、活动账号或作品所有者字段。
- v1–v7 旧账号和旧作品不迁移；检测到旧版本数据时直接清空，并以空白 v8 作品库启动。
- 旧手绘来源、残破边和粗线数据不恢复。
- 同一浏览器刷新或重新打开网址后可继续编辑已保存作品。
- 不同浏览器、不同设备之间不共享数据。
- 清除浏览器站点数据、使用无痕模式或更换设备后，作品可能无法恢复。
- 不提供云备份、账号找回、作品分享、公开作品库、统计、权限或远程管理。

## 创作编辑

- 上传 PNG、JPEG、WebP，单文件不超过 10 MB。
- 图片在本地降采样到最长边 1600 像素后处理。
- “图片编辑”和“黑白稿编辑”始终可双向切换。
- 支持最多 10 条纯色背景规则，每条可独立取样、重新取样、调整容差和删除。
- 支持矩形裁剪、四点透视裁剪和 1–80 px 图片橡皮。
- 图片橡皮可连续多笔擦除；图片橡皮和裁剪的工作图在点击草稿、保存或 A4 导出时持久化。
- 支持正方形、长方形、圆形，实际尺寸 10–100 mm。
- 支持实心剪影、轮廓线稿、0–8 级锐化、0–20 mm 内容外边距和 1–8 级轮廓粗细。
- 支持手绘画笔/橡皮独立大小、撤销重做、查看缩放和画布尺寸光标。
- 支持阳刻/阴刻、正常/左右镜像，以及无、单线、双线边框、1–8 级边框粗细和 0–20 mm 边框外边距。
- 文件名、作品名称、空作品保护、清除画布、未保存离开和替换确认继续沿用。

## 作品列表与预览

- 支持全部作品、已完成、草稿三种筛选。
- 卡片显示黑白缩略图、名称、状态和最后保存时间。
- 预览弹窗同时展示红印效果和黑白印稿。
- 已完成和草稿均支持多选、一键全选和二次确认永久删除。
- 只有已完成作品可以进入 A4 导出。

## A4 与 PDF

- P4 支持已完成作品多选添加、自动分页、拖动、90° 旋转和间距调整。
- 不提供缩放。
- A4 为纵向 210×297 mm，作品按真实毫米尺寸放置。
- PDF 包含最终黑白稿、边框、尺寸标注和裁剪线，不包含红印效果或灰色像素。
- PDF 在浏览器本地即时生成并下载，不保存导出历史。

## 范围边界

不包含：

- 登录、注册、账号切换和用户权限。
- 后端服务、数据库或业务 API。
- 跨浏览器、跨设备同步。
- 作品分享、社区、公开作品库、统计或远程管理。
- 真实打印、转印和雕刻效果验证。
- 外部 AI 或自动可刻性检查。
