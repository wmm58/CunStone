# CunStone

CunStone v0.1 是一个单浏览器本地原型，用于把已有画面制作成可打印、可转印的黑白印稿。

当前实现范围是 OpenSpec Change 1–5：本地测试登录、账号与作品数据、图片/手绘输入、纯色去底、纯黑白基础稿、手动修整、阴阳刻、镜像、边框、作品列表、预览与管理、A4 自动排版和手动调整。

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS

## 本地运行

```bash
npm install
npm run dev
```

Vite 默认在 `http://localhost:5173` 启动；端口被占用时会自动使用下一个可用端口。

验证命令：

```bash
npm test
npm run typecheck
npm run build
```

## 本地测试登录

- 手机号使用 11 位中国大陆手机号格式。
- 默认固定测试验证码：`123456`
- 可以通过 `VITE_TEST_VERIFICATION_CODE` 覆盖测试验证码；示例见 `.env.example`。
- 页面上的“获取测试验证码”只填入测试验证码，不发送真实短信。
- 不调用真实短信、身份核验或支付服务。

## 页面与路由

- `#/login`：P1 登录/注册页。
- `#/editor/new`：P2 新建作品编辑页。
- `#/editor/:workId`：按作品标识重新打开 P2 编辑页。
- `#/works`：P3 作品列表页。
- `#/export/a4`：P4 A4 排版页。

## P3 作品列表

- 支持全部作品、已完成、草稿三种筛选。
- 作品卡片显示黑白缩略图、名称、最后保存时间和状态。
- 预览弹窗同时展示纯红印效果和黑白印稿。
- 支持继续编辑和新建作品。
- 已完成筛选支持“一件全选”，已选数量显示在全选文字下方。
- 支持二次确认后永久删除已选作品。
- 已完成的已选作品可以进入 P4 排版；PDF 仍为占位。

## P4 A4 排版

- 从 P2 已完成作品或 P3 已选作品进入 P4。
- “添加作品”弹窗只展示当前账号的已完成作品，支持多选和去重。
- 左侧“已添加作品列表”显示作品、实际尺寸和总添加数量。
- 按作品实际毫米尺寸自动排版，空间不足自动生成新 A4 页面。
- 支持拖动、90° 旋转、水平间距和垂直间距调整，不提供缩放。
- 预览显示实际尺寸标注和四角裁剪线。
- “下载 PDF”在当前 Change 仍为占位，Change 6 再接真实 PDF。

## P2 图片预处理

- 支持上传 PNG、JPEG、WebP，单文件不超过 10 MB。
- 图片在本地降采样到最长边 1600 像素后处理。
- 支持正方形、长方形、圆形和自定义实际尺寸，尺寸范围为 10–100 mm。
- 支持固定线宽手绘输入和清空重画。
- 在输入画布点击背景取样，并通过 0–100 容差滑杆调整去底范围。
- 支持实心剪影和轮廓线稿两种纯黑白效果。
- 支持黑白稿画笔、橡皮、撤销、重做、50%–400% 查看缩放和 1–32 px 线宽。
- 支持阳刻/阴刻、正常/左右镜像，以及无、单线、粗线、双线、残破边五种边框。
- 手动修整保存在独立覆盖层中；撤销/重做历史只在当前编辑会话保留。
- 修改 01–04 处理参数时，如已存在手动修整会先要求确认，确认后重置修整。
- 自动执行方向归一化、透明边裁切、等比缩放、居中、锐化和印章外形裁切。
- 不处理复杂、多色或渐变背景，也不提供透视四角校正。
- 图片处理全部在浏览器本地完成，不调用自建 API、服务端或外部 AI。

## 数据与安全边界

- 所有应用数据保存在当前浏览器和当前站点的 `localStorage` 中。
- localStorage 数据结构使用 v3；打开 v1 或 v2 数据时会自动迁移。
- v3 保存压缩后的黑白修整覆盖层、线宽、阴阳刻、镜像和边框，不保存最终黑白 PNG 或撤销/重做快照。
- 不支持跨浏览器、跨设备或云同步。
- 清除站点数据后，本地账号和作品无法恢复。
- 本地账号只用于区分作品数据，不构成安全隔离；用户可以通过浏览器工具查看或修改 localStorage。
- 不保存敏感凭据、支付信息或真实身份资料。

## 当前范围

包含：

- 本地测试登录与账号复用
- 本地作品创建、命名、草稿/已完成保存
- 自动保存和手动保存
- 同一浏览器中的作品恢复
- 写入失败提示
- 图片上传、固定线宽手绘、纯色去底、容差和外形适配
- 实心剪影和轮廓线稿的纯黑白基础稿
- 黑白稿画笔、橡皮、撤销重做、查看缩放和线宽
- 阳刻/阴刻、左右镜像和五种系统边框
- 手动修整与印章设置的自动保存和同浏览器恢复
- P3 作品筛选、卡片、红印/黑白预览、继续编辑和永久删除
- P4 已完成作品添加、A4 自动分页、拖动、旋转和间距调整

不包含：

- 真实短信、身份核验和缴费
- PDF 生成与下载
- 跨设备同步和生产级安全认证
