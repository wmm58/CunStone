# a4-composition Specification

## Purpose
让用户把当前账号的已完成作品按真实毫米尺寸添加到 A4 页面，自动分页后手动调整位置、旋转和间距，并在浏览器中确认最终排版。

## Requirements

### Requirement: P4 登录保护与入口

系统必须（MUST）提供受登录保护的 A4 排版路由，并从 P2、P3 接入；P3 仍只允许添加已完成作品，P2 当前有效作品必须先自动保存为已完成再进入 P4，空作品或保存失败不得进入。

#### Scenario: 从 P3 进入

- **WHEN** 用户在 P3 选择已完成作品并点击 A4 导出
- **THEN** 系统进入 P4 并带入所选作品

#### Scenario: 从已完成作品的 P2 进入

- **WHEN** 已完成作品在 P2 点击 A4 导出
- **THEN** 系统重新保存当前状态为已完成，然后进入 P4 并加入该作品

#### Scenario: 从编辑中的 P2 进入

- **WHEN** 草稿或新作品在 P2 有名称和可打印内容并点击 A4 导出
- **THEN** 系统先自动保存为已完成作品，再进入 P4 并加入该作品

#### Scenario: P2 空作品不能进入

- **WHEN** P2 当前作品没有可打印内容时点击 A4 导出
- **THEN** 系统停在 P2，显示“作品为空”且不进入 P4

#### Scenario: P2 保存失败不能进入

- **WHEN** P2 导出前的自动保存失败
- **THEN** 系统停在 P2、保留当前内容并显示保存失败提示

#### Scenario: 未登录访问

- **WHEN** 没有活动本地账号访问 P4
- **THEN** 系统跳转登录页且不展示作品

### Requirement: 已添加作品列表

P4 左侧栏标题必须（MUST）为“已添加作品列表”，底部必须提供“添加作品”按钮，并显示总添加作品数量。

#### Scenario: 添加与移除

- **WHEN** 用户添加或移除作品
- **THEN** 左侧列表与总数量同步更新

### Requirement: 添加作品弹窗

点击“添加作品”必须（MUST）打开弹窗，只展示当前账号已完成作品的名称和缩略图，支持多选并在确认后返回 P4。

#### Scenario: 多选添加

- **WHEN** 用户勾选多个已完成作品并点击确定
- **THEN** 弹窗关闭、作品加入列表并显示总数量

#### Scenario: 排除草稿和重复

- **WHEN** 系统展示或添加作品
- **THEN** 草稿不出现，已在列表中的作品不重复添加

### Requirement: A4 初始自动排版

系统必须（MUST）以 A4 纵向页面和作品实际毫米尺寸生成初始排版，自动留出水平、垂直间距，并在当前页放不下时增加新页。

#### Scenario: 单页自动排版

- **WHEN** 添加作品后总尺寸能放入一页
- **THEN** 系统生成无重叠的单页布局

#### Scenario: 自动分页

- **WHEN** 作品在当前页剩余空间放不下
- **THEN** 系统把后续作品放入新 A4 页面并显示总页数

### Requirement: 页面切换

P4 必须（MUST）显示当前页码和总页数，并提供上一页、下一页操作。

#### Scenario: 多页切换

- **WHEN** 排版产生多页
- **THEN** 用户可以在页面之间切换并查看对应作品

### Requirement: 手动拖动

用户必须（MUST）可以拖动当前页作品调整位置；作品应限制在 A4 页面范围内。

#### Scenario: 拖动作品

- **WHEN** 用户按住并拖动作品
- **THEN** 作品按拖动距离更新毫米位置且不越出页面边界

### Requirement: 旋转与间距

P4 必须（MUST）支持作品旋转、水平间距和垂直间距调整，不得提供缩放功能。

#### Scenario: 旋转作品

- **WHEN** 用户调整选中作品的旋转角度
- **THEN** 作品视觉旋转且尺寸标注保持可读

#### Scenario: 调整间距

- **WHEN** 用户修改水平或垂直间距
- **THEN** 自动排版按新间距重新布局

#### Scenario: 禁止缩放

- **WHEN** 用户查看 P4 工具栏
- **THEN** 不出现缩放或尺寸缩放入口

### Requirement: 尺寸标注与裁剪线

每枚作品必须（MUST）在 P4 中显示实际尺寸标注和四角裁剪线预览。

#### Scenario: 方章与圆章标记

- **WHEN** 页面显示方形、长方形或圆形作品
- **THEN** 对应尺寸文本和裁剪线可见

### Requirement: PDF 占位边界

Change 5 必须（MUST）只展示 PDF 下载占位，不生成或保存 PDF。

#### Scenario: 点击 PDF 占位

- **WHEN** 用户点击“下载 PDF”占位按钮
- **THEN** 系统提示后续 Change 提供，不下载文件

### Requirement: Change 5 基础验收流程

系统必须（MUST）支持已完成作品多选添加到 A4、自动排版、拖动、旋转、间距调整和分页预览的完整本地流程。

#### Scenario: 完整排版流程

- **WHEN** 用户从 P3 带入多件已完成作品并完成排版调整
- **THEN** P4 的列表、总数量、页数、毫米位置和标记保持一致

### Requirement: P4 下载入口位置

P4 必须（MUST）将“下载 PDF”按钮放在顶部排版工具栏右侧，并删除底部的“拖动作品调整位置；PDF 仅包含黑白稿，不包含红印效果”等说明文字。

#### Scenario: 顶部下载

- **WHEN** 用户进入 P4
- **THEN** “下载 PDF”显示在顶部排版工具栏右侧

#### Scenario: 删除底部说明

- **WHEN** 用户查看 A4 画布底部
- **THEN** 不显示拖动与 PDF 黑白稿说明文字
