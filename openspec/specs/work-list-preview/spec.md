# work-list-preview Specification

## Purpose
让登录用户在 P3 中筛选、预览和管理自己的已保存作品，并从作品卡片继续编辑或选择已完成作品进入后续导出流程。

## Requirements

### Requirement: P3 登录保护与路由

系统必须（MUST）提供作品列表路由，并只允许存在活动本地账号的用户访问；未登录用户必须被带回 P1。

#### Scenario: 已登录访问

- **WHEN** 活动本地账号访问作品列表路由
- **THEN** 系统显示当前账号的 P3 作品列表

#### Scenario: 未登录访问

- **WHEN** 没有活动本地账号的用户访问作品列表路由
- **THEN** 系统跳转到登录页且不展示任何作品

### Requirement: P2 与 P3 导航

P2 必须（MUST）提供进入作品列表的入口；P3 必须提供新建作品和继续编辑入口。

#### Scenario: 从 P2 进入 P3

- **WHEN** 用户点击 P2 的“作品列表”
- **THEN** 系统进入 P3

#### Scenario: 新建与继续编辑

- **WHEN** 用户在 P3 点击“新建作品”或某张作品的“继续编辑”
- **THEN** 系统进入对应的 P2 新建或编辑路由

### Requirement: 作品筛选

P3 必须（MUST）提供全部作品、已完成、草稿三种筛选，并只显示当前账号数据。

#### Scenario: 三种筛选

- **WHEN** 用户切换全部作品、已完成或草稿
- **THEN** 列表只显示与所选状态匹配的当前账号作品

#### Scenario: 空筛选

- **WHEN** 所选筛选没有作品
- **THEN** 系统显示明确的空状态，不显示其他账号或错误状态作品

### Requirement: 作品卡片

每张作品卡片必须（MUST）显示黑白缩略图、作品名称、作品状态和最后保存时间。

#### Scenario: 已完成作品卡片

- **WHEN** P3 渲染已完成作品
- **THEN** 卡片显示最近保存的黑白稿缩略图、名称、已完成状态和时间

#### Scenario: 草稿作品卡片

- **WHEN** P3 渲染草稿作品
- **THEN** 卡片显示草稿标记，不允许勾选进入导出

### Requirement: 作品预览弹窗

P3 必须（MUST）提供作品预览弹窗，同时展示纯红印效果和黑白印稿，并可关闭或继续编辑。

#### Scenario: 打开预览

- **WHEN** 用户点击作品卡片的“预览”
- **THEN** 弹窗显示该作品名称、红印效果和黑白印稿

#### Scenario: 关闭与继续编辑

- **WHEN** 用户在预览弹窗点击关闭或继续编辑
- **THEN** 系统分别关闭弹窗或进入对应 P2 编辑页

#### Scenario: 红印颜色

- **WHEN** 系统渲染红印效果
- **THEN** 黑色印稿内容映射为纯红，背景保持纯白，不模拟印泥纹理

### Requirement: 已完成作品选择

P3 必须（MUST）只允许已完成的当前账号作品被选择；选择数量必须显示在“一件全选”下方。

#### Scenario: 手动选择

- **WHEN** 用户在已完成筛选中勾选一件或多件作品
- **THEN** 已选数量立即更新

#### Scenario: 一件全选

- **WHEN** 用户点击“一件全选”
- **THEN** 当前已完成筛选中的全部作品被选中，数量显示在全选文字下方

#### Scenario: 切换筛选

- **WHEN** 用户离开已完成筛选
- **THEN** 系统清空已完成作品选择，避免误操作

### Requirement: 删除已选作品

系统必须（MUST）支持删除已选作品；删除前展示二次确认，确认后从 localStorage 永久删除，取消则不改变数据。

#### Scenario: 确认删除

- **WHEN** 用户选择作品、点击删除并确认
- **THEN** 所选当前账号作品被永久删除，列表和选择数量同步更新

#### Scenario: 取消删除

- **WHEN** 用户在删除确认中取消
- **THEN** 作品和选择状态保持不变

### Requirement: 删除权限与原子性

删除操作必须（MUST）只删除当前本地账号拥有的作品，并通过一次本地写入完成整批删除。

#### Scenario: 不删除其他账号作品

- **WHEN** 删除请求包含其他账号的作品标识
- **THEN** 系统忽略不属于当前账号的标识

### Requirement: A4 占位边界

Change 4 必须（MUST）只在 P3 展示 A4 导出占位，不进入 P4、不生成 PDF。

#### Scenario: 点击占位

- **WHEN** 用户点击 P3 的 A4 导出占位按钮
- **THEN** 系统显示后续 Change 提供提示，不跳转 P4

### Requirement: Change 4 基础验收流程

系统必须（MUST）支持同一浏览器内从 P2 进入 P3、筛选、预览、继续编辑、全选和永久删除的完整流程。

#### Scenario: 完整管理流程

- **WHEN** 用户拥有草稿和已完成作品，进入 P3 完成筛选、预览、全选并确认删除
- **THEN** 列表、预览内容、选择数量与 localStorage 数据保持一致
