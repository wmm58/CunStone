# editor-workspace-controls Specification

## Purpose
定义 CunStone P2 创作编辑页的固定画布、双工具模式、保存与空作品保护、清除画布，以及既有本地作品状态的兼容迁移，让编辑工作区稳定、可恢复且不会误保存空内容。

## Requirements

### Requirement: P2 固定画布与独立工具滚动

P2 必须（MUST）锁定为桌面浏览器视口高度，右侧画布占满工具区之外的剩余空间，默认正方形作品画布按 1:1 等比显示且不拉伸；左侧工具区必须拥有独立纵向滚动，能够上下查看当前模式下的全部工具。

#### Scenario: 滚动左侧长工具区

- **WHEN** 用户在当前模式工具超过可视高度时滚动左侧工具区
- **THEN** 工具区上下滚动，中央画布保持在可视区域中的固定位置

#### Scenario: 页面出现纵向滚动

- **WHEN** 页面因顶部信息或其他内容出现纵向滚动条
- **THEN** 中央画布不随页面滚动移出屏幕中间的可视工作区

#### Scenario: 右侧画布铺满

- **WHEN** 用户在桌面视口进入 P2
- **THEN** 画布区域占用左侧工具区以外的全部可用宽高，不保留原有右侧空白列

#### Scenario: 默认一比一显示

- **WHEN** 用户新建默认正方形作品
- **THEN** 画布内容按 1:1 宽高比等比显示，不发生横向或纵向拉伸

### Requirement: P2 双工具模式与工具可见性

P2 必须（MUST）在左侧工具区顶部提供互斥的“图片编辑”和“黑白稿编辑”模式；默认进入“图片编辑”，该模式只显示上传图片和纯色背景去除工具，切换为“黑白稿编辑”后只显示外形尺寸、效果适配、黑白稿编辑和阴/阳刻与边框工具。

#### Scenario: 默认输入编辑

- **WHEN** 用户进入 P2 创作编辑页
- **THEN** 工具模式为“图片编辑”，入口位于左侧工具区，只显示上传图片和背景去除工具

#### Scenario: 切换黑白稿去底

- **WHEN** 作品已有可用黑白基础稿且用户切换到“黑白稿去底”
- **THEN** 模式名称显示为“黑白稿编辑”，左侧只显示外形尺寸、效果适配、黑白稿编辑和阴/阳刻与边框工具

#### Scenario: 尚无黑白基础稿

- **WHEN** 用户尚未上传可处理图片并尝试进入“黑白稿去底”
- **THEN** 系统仍切换到“黑白稿编辑”，显示空画布和需要先生成黑白基础稿的说明，但不执行不可用的画笔或橡皮操作

#### Scenario: 编辑操作后立即切换

- **WHEN** 用户刚完成图片橡皮或裁剪并立即点击另一模式
- **THEN** 系统直接完成切换，不等待保存、不刷新源图、不重置工具或背景规则

### Requirement: P2 模式切换保留编辑状态

在“图片编辑”和“黑白稿编辑”之间切换必须（MUST）只改变工具区与对应画布视图，不得清空或重置图片、背景颜色规则、轮廓粗细、尺寸、效果、手动修整、撤销重做历史、阴阳刻、镜像、边框或边框粗细。

#### Scenario: 来回切换模式

- **WHEN** 用户设置图片与多项参数后切换为“黑白稿去底”，再切回“输入编辑”
- **THEN** 图片、背景规则、尺寸和效果仍与切换前一致

#### Scenario: 保留黑白编辑结果

- **WHEN** 用户已有手动修整和撤销历史后短暂切换工具模式
- **THEN** 当前黑白修整结果与撤销重做历史在返回后保持可用

### Requirement: P2 保存文案与完成状态

P2 顶部主保存按钮文案必须（MUST）为“保存”，不得显示“保存（已完成）”；点击“保存”必须将作品标记为已完成，点击“草稿”必须保存为草稿。页面不得常驻显示“草稿”“未保存”状态标签或本地账号安全说明。

#### Scenario: 保存为已完成

- **WHEN** 用户点击 P2 的“保存”
- **THEN** 作品状态更新为已完成，页面不常驻显示草稿或未保存状态文字

#### Scenario: 保存为草稿

- **WHEN** 用户点击 P2 的“草稿”
- **THEN** 作品状态更新为草稿，页面不常驻显示草稿或未保存状态文字

### Requirement: 空作品保存保护

保存草稿或保存已完成前，系统必须（MUST）校验作品是否有可打印内容。没有图片源，或在应用当前背景规则、效果与手动修整后、添加系统边框及执行阴刻反转前没有任何黑色保留像素时，作品视为空；系统必须阻止两种保存并提示“作品为空”。

#### Scenario: 全新空画布保存

- **WHEN** 用户未上传图片时点击“草稿”或“保存”
- **THEN** 系统不创建作品并显示“作品为空”

#### Scenario: 内容被全部擦除后保存

- **WHEN** 用户已有图片但手动修整后主体区域没有任何黑色保留像素，并点击“草稿”或“保存”
- **THEN** 系统不保存空白结果并显示“作品为空”

#### Scenario: 仅有边框也不视为有效内容

- **WHEN** 主体内容和手动修整结果均无黑色像素，仅因选择了系统边框或阴刻而产生黑色像素
- **THEN** 系统仍将作品判定为空并阻止保存

### Requirement: 空作品不覆盖自动保存

作品为空时，自动保存必须（MUST）不新建空白作品，也不得用空白状态覆盖当前浏览器中最后一次有效保存的作品版本；只有重新产生可打印内容后，自动保存才可继续写入。

#### Scenario: 新建空白作品等待自动保存

- **WHEN** 用户新建作品但尚未上传可打印图片并超过自动保存延迟
- **THEN** localStorage 中不新增空白作品记录

#### Scenario: 清除已保存作品

- **WHEN** 用户清除一件已保存作品的画布并超过自动保存延迟
- **THEN** 最后一次有效保存版本仍保留，空画布不写入该作品的持久状态

### Requirement: P2 清除画布

P2 必须（MUST）提供“清除”按钮；执行后必须清空当前图片源、全部背景颜色规则、黑白修整覆盖层、撤销重做历史及派生黑白结果，并回到可重新上传的空白画布。清除不得删除作品记录、作品名称、外形和实际宽高。

#### Scenario: 清除已有内容

- **WHEN** 用户在已有图片、多个背景规则和手动修整时点击“清除”
- **THEN** 图片、背景规则、修整、撤销重做历史和派生黑白结果全部清空，作品名称与尺寸设置保留

#### Scenario: 清除后重新开始

- **WHEN** 用户清除画布后点击空白画布中心或 02 上传入口
- **THEN** 系统允许重新选择并上传图片

### Requirement: 图片编辑工作图延后持久化

图片橡皮、矩形裁剪和透视裁剪产生的工作图修改必须（MUST）保留在当前编辑会话中；系统不得在每次橡皮抬笔或裁剪应用后自动写入 localStorage。用户明确点击“草稿”“保存”或“A4 导出”时，系统必须使用最新工作图生成作品数据并持久化。

#### Scenario: 连续橡皮但不保存

- **WHEN** 用户连续完成多笔图片橡皮并等待超过普通自动保存延迟
- **THEN** localStorage 中仍保留上次显式保存的源图，当前工作图继续在页面内可编辑

#### Scenario: 显式保存工作图

- **WHEN** 用户完成图片橡皮或裁剪后点击“草稿”“保存”或“A4 导出”
- **THEN** 系统先使用最新工作图生成源图数据，再完成对应保存或导出流程

#### Scenario: 未保存工作图离开

- **WHEN** 用户存在尚未显式保存的图片工作图并触发离开或替换
- **THEN** 系统继续使用现有未保存提示，避免工作图被静默丢弃

### Requirement: P2 工具模块图标

P2 的工具模块必须（MUST）使用可访问的 SVG 图标替代数字序号，模块名称继续显示为文字；模式切换、图标按钮和工具标题必须提供可读的无障碍名称。

#### Scenario: 工具模块不再显示数字序号

- **WHEN** 用户查看 P2 左侧工具区
- **THEN** 上传图片、背景去除、裁剪、橡皮、外形尺寸、效果适配、手绘和阴/阳刻边框模块均以图标加名称显示，不出现数字序号

#### Scenario: 图标可访问

- **WHEN** 用户使用无障碍名称查询模块图标
- **THEN** 每个图标都能返回对应的模块名称

### Requirement: P2 作品名称同排布局

P2 的作品名称标签和输入框必须（MUST）位于同一行，名称仍可编辑，操作按钮与名称区域在顶部保持清晰分组。

#### Scenario: 名称标签与输入框同排

- **WHEN** 用户进入 P2
- **THEN** “作品名称”标签位于名称输入框左侧同一行，不显示为上下堆叠

### Requirement: P2 保存结果弹窗

点击“草稿”或“保存”成功后，系统必须（MUST）使用弹窗说明保存结果和本地数据范围，不再把这些信息常驻在页面上。

#### Scenario: 草稿保存成功

- **WHEN** 用户点击“草稿”且保存成功
- **THEN** 系统显示标题“草稿已保存”和正文“作品已保存到当前浏览器。清除站点数据或更换设备后可能无法恢复。”

#### Scenario: 已完成保存成功

- **WHEN** 用户点击“保存”且保存成功
- **THEN** 系统显示标题“作品已保存”和正文“作品已保存到当前浏览器，可继续编辑，也可在作品列表中预览或进入 A4 排版。”

#### Scenario: 关闭保存结果弹窗

- **WHEN** 用户关闭保存结果弹窗
- **THEN** 页面继续停留在当前作品编辑状态，不常驻显示草稿、未保存、账号或权限说明

### Requirement: P2 未保存内容处理

P2 存在未保存修改时，用户点击“作品列表”或其他内部离开动作前，系统必须（MUST）弹出未保存处理弹窗，提供“继续编辑”“保存草稿并继续”“直接离开”。

#### Scenario: 保存草稿后离开

- **WHEN** 未保存弹窗中用户选择“保存草稿并继续”且保存成功
- **THEN** 系统保存草稿并完成原离开动作

#### Scenario: 直接离开

- **WHEN** 用户选择“直接离开”
- **THEN** 系统放弃本次未保存修改并完成原离开动作

#### Scenario: 保存失败阻止离开

- **WHEN** 用户选择“保存草稿并继续”但保存失败
- **THEN** 系统停留在 P2、保留当前内容并显示失败提示

#### Scenario: 继续编辑

- **WHEN** 用户选择“继续编辑”
- **THEN** 系统关闭弹窗，不离开当前页面

### Requirement: P2 重新上传替换确认

P2 当前画布已有图片或可打印内容时，用户点击上传图片入口或画布上传入口后，系统必须（MUST）先显示“替换当前作品？”弹窗，说明替换会用新图片重新开始，并提供“取消”“保存草稿并替换”“直接替换”。

#### Scenario: 保存草稿后替换

- **WHEN** 用户选择“保存草稿并替换”且保存成功
- **THEN** 系统保存当前草稿并打开新图片选择器

#### Scenario: 直接替换

- **WHEN** 用户选择“直接替换”
- **THEN** 系统打开新图片选择器，选中图片后清空原图片、背景规则和黑白修整并载入新图片

#### Scenario: 取消替换

- **WHEN** 用户选择“取消”
- **THEN** 系统关闭弹窗，不打开图片选择器且当前内容保持不变

#### Scenario: 保存失败阻止替换

- **WHEN** 用户选择“保存草稿并替换”但保存失败
- **THEN** 系统不打开图片选择器、保留当前内容并显示失败提示

### Requirement: P2 直接 A4 导出前自动保存

P2 的“A4 导出”必须（MUST）先校验作品名称和可打印内容，再将当前作品自动保存为已完成，保存成功后进入 P4 并加入当前作品；空作品、无名称或保存失败时必须停留在 P2 并显示原因。

#### Scenario: 草稿作品直接导出

- **WHEN** 草稿或编辑中的有效作品点击“A4 导出”
- **THEN** 系统自动保存为已完成作品，然后进入 P4 并加入该作品

#### Scenario: 新作品直接导出

- **WHEN** 尚未创建记录的新作品有名称和有效内容并点击“A4 导出”
- **THEN** 系统创建已完成作品，然后进入 P4 并加入该作品

#### Scenario: 空作品不能直接导出

- **WHEN** 当前作品没有可打印内容时点击“A4 导出”
- **THEN** 系统显示“作品为空”并停留在 P2

#### Scenario: 保存失败不能进入 P4

- **WHEN** 自动保存触发存储失败
- **THEN** 系统停留在 P2、保留当前内容并显示保存失败提示
