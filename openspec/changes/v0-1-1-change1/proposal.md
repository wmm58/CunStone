# Proposal（提案）

## Why（为什么）

CunStone v0.1 先做单浏览器本地原型，需要建立一套可演示、可恢复的本地账号与作品基础，后续的创作编辑、作品列表和导出能力才能继续建设。本次变更使用浏览器本地存储完成登录入口、作品持久化和作品生命周期，为后续变更提供统一的本地账号与作品模型。

## What Changes（变更内容）

- 增加 P1 手机号注册/登录流程，使用固定测试验证码完成本地测试身份进入。
- 登录成功后直接进入 P2 创作编辑页外壳。
- 使用 localStorage 建立本地用户与作品数据基础，并按本地账号区分作品归属。
- 增加作品名称、草稿/已完成状态、创建时间、最后保存时间和自动保存基础。
- 支持用户创建并命名作品、保存为草稿，并在之后重新打开。
- 为本地存储建立统一适配边界，后续切换到服务端或 IndexedDB 时不需要重写页面行为。
- 本次变更不包含真实短信、身份核验、缴费、服务端账号、跨设备同步、图片处理、作品列表和导出。

## Capabilities（能力）

### New Capabilities（新增能力）

- `change1`：本地测试账号入口、按本地账号区分作品、localStorage 持久化、作品命名、草稿/已完成状态、自动保存基础和恢复行为。

### Modified Capabilities（修改能力）

无。

## Impact（影响）

- 涉及 P1 登录/注册页和 P2 创作编辑页外壳。
- 涉及 Vite + React + TypeScript + Tailwind CSS 前端基础、localStorage 适配层和作品生命周期模型。
- 固定测试验证码只用于本地演示，不代表真实认证安全能力。
- 不支持跨浏览器、跨设备、多用户安全隔离或云同步。
- 不涉及图片编辑器、作品列表预览、A4 排版或 PDF 导出行为。
