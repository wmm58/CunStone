# 任务（Tasks）

## 1. 前端基础与本地存储

- [x] 1.1 使用 Vite + React + TypeScript + Tailwind CSS 建立可运行前端工程；验证开发服务器可以启动，基础测试和构建命令可执行。
- [x] 1.2 实现统一 localStorage 适配层，包含命名空间、结构版本、读取、写入、删除和异常数据回退；用自动化测试验证正常读写与损坏数据不会导致页面崩溃。
- [x] 1.3 实现本地用户数据，包含唯一规范化手机号和创建时间；验证首次创建、重复手机号复用和读取。
- [x] 1.4 实现本地作品数据，包含标识、所属本地账号标识、作品名称、草稿/已完成状态、创建时间和最后保存时间；验证创建、读取和更新。
- [x] 1.5 记录固定测试验证码和 localStorage 单浏览器限制；验证按文档使用时不会调用真实短信或服务端接口。

## 2. 本地测试登录

- [x] 2.1 实现客户端固定测试验证码校验；验证正确验证码通过、错误验证码失败，且不调用外部短信服务。
- [x] 2.2 实现合并的 P1 注册/登录行为：首次手机号登录时创建本地账号，后续登录复用同一账号；验证不会创建重复本地账号。
- [x] 2.3 实现本地活动账号状态；验证没有活动账号时访问 P2 会被带回 P1，且不展示作品数据。

## 3. P1 登录/注册页

- [x] 3.1 按线框结构实现 P1 的手机号、固定验证码和登录/注册控件；验证用户可以输入测试凭据并提交。
- [x] 3.2 为 P1 增加手机号缺失和验证码错误的校验与提示；验证错误提交不会创建本地账号，也不会设置活动账号。
- [x] 3.3 本地登录成功后直接将用户跳转到 P2 创作编辑页外壳；验证目标页面是 P2，而不是作品列表。

## 4. 本地作品生命周期

- [x] 4.1 实现本地账号创建作品，作品名称可编辑且不能为空，默认状态为草稿；验证新作品归属于当前本地账号。
- [x] 4.2 实现草稿保存和已完成保存操作，并由客户端生成最后保存时间；验证草稿保持草稿、已完成变为已完成，且重复保存保留已完成状态。
- [x] 4.3 实现按本地账号读取和展示作品；验证切换本地账号后只显示当前账号作品，并在界面和文档中明确这不是安全隔离。
- [x] 4.4 实现作品元数据自动保存，以及可观察的已保存/未保存/错误状态；验证只有 localStorage 写入成功后最后保存时间才变化，失败后可以重试。
- [x] 4.5 增加 localStorage 写入失败或容量不足时的错误提示；验证失败不会静默丢失当前输入，用户可以重试。

- [x] 5.3 增加 P2 新建草稿入口；验证当前本地账号可以创建、命名并保存草稿。
