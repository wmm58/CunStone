# 设计（Design）

## Context

Change 4 已提供 P3 已完成作品选择和临时导出占位。P4 需要把作品实际毫米尺寸转换为 A4 页面布局，同时保持选择与布局为临时状态，不修改作品或 localStorage。

## Goals / Non-Goals

**目标：**

- 新增受保护 P4 路由、添加作品弹窗、列表和 A4 预览。
- 使用毫米模型完成自动排版、分页、拖动、旋转和间距调整。
- 复用已完成作品的黑白缩略图。

**非目标：**

- 不生成 PDF、不保存排版或导出记录。
- 不提供缩放、自由缩放、多元素编辑或作品修改。
- 不验证真实打印和雕刻效果。

## Decisions

### 决策 1：P4 使用临时导出会话

新增内存级 `exportSession` 保存从 P2/P3 带入的作品 ID。P4 页面加载时只接受当前账号已完成作品；刷新后不保证恢复临时选择。

### 决策 2：A4 使用真实毫米模型

页面固定 210×297 mm，默认边距 12 mm。每个作品使用 `widthMm`、`heightMm`、`xMm`、`yMm`、`rotationDeg` 表示。屏幕以固定比例把毫米转换为像素，不改变 PDF 所需毫米数据。

### 决策 3：确定性网格自动排版

按添加顺序逐件放置：

- 从左到右排列。
- 当前行宽度不足时换行。
- 当前页高度不足时新增页面。
- 水平/垂直间距默认 5 mm，可调 0–30 mm。

间距变化触发重新自动排版；手动位置可在自动排版后拖动调整。

### 决策 4：拖动只在当前页面内

指针移动距离按屏幕像素换算为毫米并更新 `xMm/yMm`，位置限制在 A4 页面边界。拖到页面外不跨页，跨页通过列表和分页保持确定性。

### 决策 5：旋转只作用于视觉

每个作品保存 0°、90°、180°、270° 四档旋转。旋转不改变实际宽高字段或作品数据；尺寸标注仍按未旋转实际尺寸显示。

### 决策 6：添加作品弹窗复用已完成作品数据

弹窗使用 `listActiveUserWorksByStatus("completed")`，排除已添加 ID，显示名称、尺寸、状态和黑白缩略图。确认后一次性加入列表。

### 决策 7：P2/P3 入口

- P2 只有已完成状态可以进入 P4；草稿显示提示。
- P3 只有在已完成筛选中选择的 ID 可以进入 P4。
- 直接访问 P4 时允许从空列表开始添加。

### 决策 8：打印辅助标记

P4 为每件作品显示尺寸文字和四角裁剪线；这些是页面 DOM 预览，Change 6 在 PDF 中使用相同毫米位置和标记。

### 决策 9：PDF 仍为占位

“下载 PDF”按钮只显示后续 Change 提示，不调用文件生成。

## Risks / Trade-offs

- 旋转作品可能与相邻作品重叠 → 用户通过拖动和间距自行调整。
- 间距重排会覆盖手动位置 → 页面明确提示“调整间距将重新自动排版”。
- 临时会话刷新会丢失 → 蓝图将 P4 选择定义为非持久对象。
- 屏幕比例与打印机不同 → 页面显示毫米和 1:1 数据，真实打印仍不作为验收条件。

## Test Strategy

- 纯函数：A4 分页、网格位置、边界 clamp、旋转归一化。
- 组件：添加作品弹窗、多选、去重、列表数量、页切换、拖动、旋转、间距和 PDF 占位。
- 路由：未登录保护、P2/P3 入口、草稿拒绝。
- 集成：P3 选择 → P4 添加 → 自动分页 → 拖动/旋转/间距 → 页面切换。
- 真实 Chrome：固定作品完成多页排版截图检查。

## Migration Plan

不修改持久数据结构；回滚移除 P4 路由和临时会话即可。
