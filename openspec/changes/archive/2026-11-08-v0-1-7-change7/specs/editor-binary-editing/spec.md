# Spec Delta

## ADDED Requirements

### Requirement: 历史残破边兼容

升级后，系统必须（MUST）禁止新建残破边，但既有保存了残破边的作品必须继续按原参数渲染、预览和导出；用户选择其他边框后不得再切回新建残破边。

#### Scenario: 打开历史残破边作品

- **WHEN** 用户打开升级前已保存残破边的作品
- **THEN** P2 与 P3 预览继续显示该历史边框，不自动改为其他样式

#### Scenario: 历史残破边导出

- **WHEN** 用户把未修改边框的历史残破边作品下载为 PDF
- **THEN** PDF 继续使用该作品保存的残破边结果

#### Scenario: 历史作品改选其他边框

- **WHEN** 用户把历史残破边作品改为单线、双线或无边框
- **THEN** 界面不提供重新选择残破边的入口

### Requirement: 历史粗线迁移

升级后，系统必须（MUST）不再提供新建“粗线”按钮；既有粗线边框作品必须迁移为单线边框并换算到接近原视觉宽度的边框粗细，继续在 P2、P3 和 PDF 中渲染。

#### Scenario: 历史粗线作品迁移

- **WHEN** 系统读取保存了粗线边框的旧作品
- **THEN** 边框样式变为单线，边框粗细设置为等效旧粗线的宽度

#### Scenario: 历史粗线作品预览

- **WHEN** 用户打开迁移后的历史粗线作品
- **THEN** P2、P3 和 PDF 继续显示可见边框，不因粗线选项删除而消失

### Requirement: 手绘模块与独立工具大小

P2 的原黑白稿编辑模块必须（MUST）改名为“手绘”；画笔和橡皮分别保存大小，选择画笔时只显示画笔大小滑杆，选择橡皮时只显示橡皮大小滑杆。

#### Scenario: 手绘画笔

- **WHEN** 用户选择画笔
- **THEN** 手绘区显示画笔大小滑杆和当前 px 数值

#### Scenario: 手绘橡皮

- **WHEN** 用户选择橡皮
- **THEN** 手绘区显示橡皮大小滑杆和当前 px 数值

#### Scenario: 独立保存

- **WHEN** 用户分别设置画笔和橡皮大小并保存
- **THEN** 重新打开作品后两种大小分别恢复

### Requirement: 手绘尺寸光标

用户使用画笔或橡皮在画布操作时，画布必须（MUST）显示与当前工具大小一致的圆形光标，并在界面显示当前工具名称和 px 数值。

#### Scenario: 光标尺寸

- **WHEN** 用户移动画笔或橡皮光标
- **THEN** 圆形光标随当前工具大小变化，界面显示对应名称和 px 数值

### Requirement: 边框粗细跨页面一致

边框粗细必须（MUST）由同一份最终黑白渲染状态驱动，并在 P2 编辑画布、P3 红印与黑白预览、P4 缩略图和 PDF 中保持一致。

#### Scenario: P2 调整后预览

- **WHEN** 用户在 P2 调整边框粗细并保存
- **THEN** P3 的红印效果和黑白印稿使用相同粗细

#### Scenario: PDF 输出边框粗细

- **WHEN** 用户把带边框粗细设置的作品下载为 PDF
- **THEN** PDF 中边框粗细与 P3 黑白预览一致

## MODIFIED Requirements

### Requirement: P2 黑白稿编辑入口

P2 必须（MUST）始终允许在“图片编辑”和“黑白稿编辑”之间双向切换，不以是否存在黑白基础稿作为切换条件。没有可用基础稿时，系统仍显示黑白稿工具区和空画布说明，但依赖基础稿的画笔、橡皮、撤销重做和预览操作禁用。可用基础稿包括新上传图片和升级前保存的手绘作品。

#### Scenario: 有基础稿时进入编辑

- **WHEN** 用户已上传图片或打开历史手绘作品，且系统生成了黑白基础稿
- **THEN** 用户可以进入“黑白稿编辑”模式并看到外形尺寸、效果适配、黑白稿编辑和阴/阳刻与边框工具

#### Scenario: 无基础稿时禁用编辑

- **WHEN** 用户尚未提供图片
- **THEN** 用户可以进入“黑白稿编辑”查看空画布和工具说明，但画笔、橡皮等编辑操作保持禁用

#### Scenario: 任意时刻返回图片编辑

- **WHEN** 用户处于黑白稿编辑模式，无论是否已有基础稿或手动修整
- **THEN** 用户都可以立即切回图片编辑，状态不被重置

### Requirement: 系统边框

P2 必须（MUST）提供无、单线、双线三种新建边框选择，不得提供粗线和残破边；边框必须适配方形、长方形和圆形印章，并提供 1–8 级边框粗细滑杆和 0–20 mm 边框外边距滑杆，步进 0.1 mm，默认外边距为 0。

#### Scenario: 选择边框

- **WHEN** 用户查看 06 的边框选项
- **THEN** 只出现无边框、单线和双线，不出现粗线或残破边

#### Scenario: 圆形边框

- **WHEN** 用户为圆形印章选择边框
- **THEN** 边框沿圆形边界显示，不出现在圆形范围外的白色角落

#### Scenario: 调整边框粗细

- **WHEN** 用户拖动边框粗细滑杆
- **THEN** 当前边框线宽按 1–8 级设置实时变化

#### Scenario: 调整边框外边距

- **WHEN** 用户拖动边框外边距滑杆
- **THEN** 边框与画布外边缘之间的距离按毫米值实时变化，主体内容和边框粗细保持不变

#### Scenario: 边框外边距为零

- **WHEN** 用户将边框外边距设为 0 mm
- **THEN** 边框外沿贴齐画布外边缘

#### Scenario: 无边框时禁用粗细

- **WHEN** 用户选择“无边框”
- **THEN** 边框粗细和边框外边距控件禁用，不应用边框线宽或边框间距

#### Scenario: 残破边稳定

- **WHEN** 用户使用相同作品和参数多次重新打开历史残破边
- **THEN** 缺口位置保持一致，不随刷新随机变化

### Requirement: 处理参数变化与手动修整冲突

当作品已有手动修整时，修改图片源、外形、尺寸、任一有效背景颜色规则的颜色或容差、剪影/轮廓效果或轮廓粗细，并且该修改会重新生成基础稿时，系统必须（MUST）在清除修整前提示用户确认；用户取消时必须保留原参数和手动修整。

#### Scenario: 确认重置修整

- **WHEN** 已有手动修整的用户修改 01–04 中会重新生成基础稿的参数并确认提示
- **THEN** 系统应用新参数、重新生成基础稿并清空手动修整与撤销重做历史

#### Scenario: 取消重置修整

- **WHEN** 已有手动修整的用户修改 01–04 处理参数后取消提示
- **THEN** 原处理参数、手动修整和撤销重做历史保持不变

#### Scenario: 变更多背景规则

- **WHEN** 已有手动修整的用户新增并取样背景颜色、重新取样、删除规则或调整任一有效规则容差
- **THEN** 系统按同一重置确认规则处理，不静默丢弃手动修整

#### Scenario: 变更轮廓粗细

- **WHEN** 已有手动修整的用户调整轮廓线稿粗细
- **THEN** 系统先请求重置确认，确认后重新生成基础稿并清空手动修整

#### Scenario: 没有手动修整

- **WHEN** 用户尚未产生手动修整并修改 01–04 处理参数
- **THEN** 系统直接重新生成基础稿，不显示重置提示

### Requirement: 保存与恢复黑白编辑状态

作品必须（MUST）保存手动修整覆盖层、画笔大小、橡皮大小、阴阳刻、镜像、边框样式、边框粗细和毫米边框外边距；在同一浏览器重新打开时必须恢复最后保存的编辑结果。

#### Scenario: 保存并重新打开

- **WHEN** 用户完成画笔、橡皮、阴刻、镜像和边框粗细设置并保存作品
- **THEN** 重新打开后恢复相同的手动像素、画笔/橡皮大小、阴阳刻、镜像、边框样式、边框粗细和边框外边距

#### Scenario: 自动保存笔画

- **WHEN** 用户完成一笔手动编辑并停止操作超过自动保存延迟
- **THEN** 最新修整结果写入 localStorage，保存状态显示成功

### Requirement: Change 3 基础验收流程

系统必须（MUST）支持从当前黑白基础稿开始，完成手动修整、印章控制、边框粗细调整、保存和同浏览器恢复的完整流程。

#### Scenario: 完整恢复流程

- **WHEN** 用户使用固定样本进入黑白稿编辑，执行画笔、橡皮、撤销、重做、调整线宽、选择阴刻、左右镜像、选择边框并调整边框粗细后保存
- **THEN** 同一浏览器重新打开作品时恢复相同黑白结果和全部印章设置

#### Scenario: 纯色去底残留修整

- **WHEN** 多颜色去底后的固定样本仍存在残留边缘
- **THEN** 用户可以使用橡皮清除残留，并把修整结果保存和恢复
