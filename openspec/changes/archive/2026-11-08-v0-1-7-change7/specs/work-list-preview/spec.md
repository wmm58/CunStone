# Spec Delta

## ADDED Requirements

### Requirement: 草稿作品多选删除

P3 草稿筛选必须（MUST）提供与已完成筛选一致的多选、一键全选、已选数量和删除布局，但不得显示 A4 导出按钮；删除仍需二次确认并永久移除作品。

#### Scenario: 草稿多选

- **WHEN** 用户进入草稿筛选
- **THEN** 草稿卡片显示选择框，工具栏显示已选数量、一键全选和删除，不显示 A4 导出

#### Scenario: 一键全选草稿

- **WHEN** 用户点击草稿筛选中的“一键全选”
- **THEN** 当前草稿全部选中，已选数量同步更新

#### Scenario: 删除草稿

- **WHEN** 用户选择草稿、点击删除并确认
- **THEN** 所选草稿永久删除，已完成作品不受影响

## MODIFIED Requirements

### Requirement: 已完成作品选择

P3 必须（MUST）只允许已完成的当前账号作品被选择；已选数量必须显示在“一键全选”按钮前面，并与“一键全选”、删除和 A4 导出保持在同一水平行内对齐。

#### Scenario: 手动选择

- **WHEN** 用户在已完成筛选中勾选一件或多件作品
- **THEN** 已选数量立即更新，并显示在“一键全选”按钮前面

#### Scenario: 一件全选

- **WHEN** 用户点击“一键全选”
- **THEN** 当前已完成筛选中的全部作品被选中，已选数量同步更新

#### Scenario: 再次点击取消全选

- **WHEN** 当前已完成筛选中的作品已全部选中，用户再次点击“一键全选”
- **THEN** 系统取消全部选择，已选数量变为 0

#### Scenario: 操作区水平对齐

- **WHEN** 用户查看 P3 的已完成筛选工具栏
- **THEN** 已选数量、“一键全选”、删除和 A4 导出在同一水平行内对齐，不出现数量单独换行或按钮高低不一致

#### Scenario: 切换筛选

- **WHEN** 用户离开已完成筛选
- **THEN** 系统清空已完成作品选择，避免误操作
