# Spec Delta

## ADDED Requirements

### Requirement: P4 下载入口位置

P4 必须（MUST）将“下载 PDF”按钮放在顶部排版工具栏右侧，并删除底部的“拖动作品调整位置；PDF 仅包含黑白稿，不包含红印效果”等说明文字。

#### Scenario: 顶部下载

- **WHEN** 用户进入 P4
- **THEN** “下载 PDF”显示在顶部排版工具栏右侧

#### Scenario: 删除底部说明

- **WHEN** 用户查看 A4 画布底部
- **THEN** 不显示拖动与 PDF 黑白稿说明文字

## MODIFIED Requirements

### Requirement: P4 登录保护与入口

系统必须（MUST）提供受登录保护的 A4 排版路由，并从 P2、P3 接入；P3 仍只允许添加已完成作品，P2 当前有效作品必须先自动保存为已完成再进入 P4，空作品或保存失败不得进入。

#### Scenario: 从 P3 进入

- **WHEN** 用户在 P3 选择已完成作品并点击 A4 导出
- **THEN** 系统进入 P4 并带入所选作品

#### Scenario: 从已完成作品的 P2 进入

- **WHEN** 已完成作品在 P2 点击 A4 导出
- **THEN** 系统重新保存当前状态为已完成，然后进入 P4 并加入该作品

#### Scenario: 从编辑中的 P2 进入

- **WHEN** 草稿或新作品在 P2 有名称和可打印内容并点击 A4 导出
- **THEN** 系统先自动保存为已完成作品，再进入 P4 并加入该作品

#### Scenario: P2 空作品不能进入

- **WHEN** P2 当前作品没有可打印内容时点击 A4 导出
- **THEN** 系统停在 P2，显示“作品为空”且不进入 P4

#### Scenario: P2 保存失败不能进入

- **WHEN** P2 导出前的自动保存失败
- **THEN** 系统停在 P2、保留当前内容并显示保存失败提示

#### Scenario: 未登录访问

- **WHEN** 没有活动本地账号访问 P4
- **THEN** 系统跳转登录页且不展示作品
