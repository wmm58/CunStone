# Spec Delta

## Purpose

让用户在 P2 中把一张已经完成的图片或手绘构图处理成适配印章实际尺寸、无灰色像素的黑白基础稿，并把输入和处理参数保存在当前浏览器的 localStorage 中。

## ADDED Requirements

### Requirement: P2 印章外形与实际尺寸

P2 必须（MUST）提供正方形、长方形、圆形和自定义长宽四种外形；实际尺寸使用毫米，用户可采用推荐值或自行修改。

#### Scenario: 选择正方形

- **WHEN** 用户选择正方形
- **THEN** 系统提供 20、25、30 mm 的推荐边长，并保持宽高相等

#### Scenario: 选择长方形

- **WHEN** 用户选择长方形
- **THEN** 系统提供 15×30 mm、20×30 mm 等推荐长宽，并允许分别修改宽和高

#### Scenario: 选择圆形

- **WHEN** 用户选择圆形
- **THEN** 系统使用直径作为宽高，并提供 20、25、30 mm 的推荐值

#### Scenario: 自定义尺寸

- **WHEN** 用户选择自定义并输入 10–100 mm 范围内的宽和高
- **THEN** 系统把该尺寸用于画布比例和后续黑白稿适配

#### Scenario: 非法尺寸

- **WHEN** 用户输入超出 10–100 mm 范围或非数字的尺寸
- **THEN** 系统阻止应用该尺寸并显示尺寸错误提示

### Requirement: 本地图片上传

P2 必须（MUST）支持上传 PNG、JPEG、WebP 图片，在浏览器本地解码，并拒绝不支持的格式或超过 10 MB 的文件。

#### Scenario: 上传有效图片

- **WHEN** 用户选择不超过 10 MB 的 PNG、JPEG 或 WebP 图片
- **THEN** 系统在本地解码并显示在 P2 输入画布中

#### Scenario: 上传不支持的格式

- **WHEN** 用户选择不支持的文件格式
- **THEN** 系统拒绝该文件、保留已有输入并显示格式错误提示

#### Scenario: 上传过大文件

- **WHEN** 用户选择的图片超过 10 MB
- **THEN** 系统拒绝该文件、保留已有输入并显示文件过大提示

### Requirement: 工作图像分辨率限制

上传图片在工作状态中的最长边必须（MUST）降采样到不超过 1600 像素，以降低 localStorage 容量风险。

#### Scenario: 大尺寸图片降采样

- **WHEN** 用户上传一张最长边超过 1600 像素的图片
- **THEN** 系统保持比例降采样到最长边 1600 像素后再进行后续处理

### Requirement: 手绘完整构图

P2 必须（MUST）提供固定线宽的黑色手绘输入，支持鼠标和触控笔绘制完整构图，并提供清空后重画的能力。

#### Scenario: 手绘输入

- **WHEN** 用户使用鼠标或触控笔在输入画布上连续绘制
- **THEN** 系统绘制可见黑色笔迹并把它作为完整输入画面

#### Scenario: 清空手绘

- **WHEN** 用户点击清空手绘画布
- **THEN** 系统删除当前手绘内容并允许重新绘制

### Requirement: 点击纯色背景

系统必须（MUST）允许用户在输入画布上点击一个背景像素来指定要移除的纯色背景。

#### Scenario: 指定白色背景

- **WHEN** 输入画面存在纯白背景且用户点击该背景
- **THEN** 系统记录白色并标记该颜色为待移除背景

#### Scenario: 指定其他纯色背景

- **WHEN** 用户点击蓝色、绿色等任意纯色背景
- **THEN** 系统记录该背景颜色并允许按容差去除

#### Scenario: 没有可用输入

- **WHEN** 用户尚未上传图片或完成手绘就尝试点击背景
- **THEN** 系统不记录背景颜色并保持无处理状态

### Requirement: 背景颜色容差

P2 必须（MUST）提供 0–100 的背景颜色容差滑杆，默认值为 20，并实时改变被判定为背景的像素范围。

#### Scenario: 调整容差

- **WHEN** 用户提高或降低背景容差滑杆
- **THEN** 系统扩大或缩小与所选背景色接近的像素移除范围，并更新画布结果

#### Scenario: 未选择背景色

- **WHEN** 用户尚未点击背景但移动容差滑杆
- **THEN** 系统保存容差值但不执行背景移除

### Requirement: 剪影与轮廓效果

系统必须（MUST）提供实心剪影和轮廓线稿两种效果，二者都输出纯黑白结果。

#### Scenario: 实心剪影

- **WHEN** 用户选择实心剪影
- **THEN** 系统把保留主体内部填成黑色，把去除区域显示为白色

#### Scenario: 轮廓线稿

- **WHEN** 用户选择轮廓线稿
- **THEN** 系统从保留主体的边缘生成黑色轮廓，并把其余区域显示为白色

### Requirement: 自动适配印章外形

系统必须（MUST）在本地自动归一化图片方向、缩放并居中可见内容，再按所选印章外形裁切，内容不得超出印章边界。

#### Scenario: 横竖图适配

- **WHEN** 用户输入横向或纵向图片并选择任一印章外形
- **THEN** 系统在本地按内容边界完成方向归一化、等比缩放和居中适配

#### Scenario: 圆形印章适配

- **WHEN** 用户选择圆形印章
- **THEN** 处理结果只保留圆形范围内的内容，圆形之外为白色

#### Scenario: 更换外形或尺寸

- **WHEN** 用户在已有输入后更换外形或修改实际尺寸
- **THEN** 系统按新外形和尺寸重新适配并更新黑白基础稿

### Requirement: 锐化与几何归一化

系统必须（MUST）在二进制化前执行本地锐化，并通过去除透明外边距、居中和形状裁切完成几何归一化。

#### Scenario: 透明边裁切

- **WHEN** 去底后的主体周围存在透明空白
- **THEN** 系统按可见内容边界裁切后再缩放到印章外形

#### Scenario: 无需额外旋转

- **WHEN** 输入图像方向和内容边界已经适合当前外形
- **THEN** 系统保持原方向，不产生无意义的旋转

### Requirement: 纯黑白基础稿

处理后的黑白基础稿必须（MUST）只包含纯黑和纯白像素，不得保留灰色或半透明中间值。

#### Scenario: 像素颜色检查

- **WHEN** 系统完成剪影或轮廓处理
- **THEN** 输出中的每个可见像素只能是黑色或白色

#### Scenario: 去除区域显示为白色

- **WHEN** 原图或去底结果中的区域被判定为不留存
- **THEN** 该区域在黑白基础稿中显示为白色

### Requirement: 保存图片处理状态

作品必须（MUST）保存输入来源、本地图片数据、外形、实际尺寸、背景颜色、容差和效果类型，以便在同一浏览器恢复处理状态。

#### Scenario: 保存并重新打开

- **WHEN** 用户设置好图片、外形、尺寸、背景色、容差和效果并保存作品
- **THEN** 在同一浏览器重新打开作品时恢复这些输入和参数，并重新生成相同黑白基础稿

### Requirement: 本地容量失败处理

当图片或处理状态无法写入 localStorage 时，系统必须（MUST）显示保存失败提示、保留当前内存中的输入，并允许用户重试。

#### Scenario: localStorage 容量不足

- **WHEN** 保存图片处理状态触发容量不足错误
- **THEN** 系统不丢失当前画布内容，显示保存失败状态，并允许再次保存

### Requirement: 不使用自建 API 或外部 AI

Change 2 的所有图片解码、去底、容差、适配、锐化和黑白化必须（MUST）在当前浏览器本地完成，不得发起业务 API 请求。

#### Scenario: 本地处理

- **WHEN** 用户上传图片并执行全部 Change 2 处理流程
- **THEN** 系统不调用自建 API、服务端、外部 AI 服务或 API Key

### Requirement: Change 2 基础验收流程

系统必须（MUST）支持从图片上传或手绘输入到保存并恢复纯黑白基础稿的完整本地流程。

#### Scenario: 上传图片完整流程

- **WHEN** 用户上传固定纯色背景样本，选择外形和尺寸，点击背景，调整容差，选择剪影并保存
- **THEN** 系统生成无灰色黑白稿，并在同一浏览器重新打开后恢复输入和参数

#### Scenario: 手绘流程

- **WHEN** 用户手绘固定样本、选择外形和尺寸、选择轮廓效果并保存
- **THEN** 系统生成无灰色黑白稿，并在同一浏览器重新打开后恢复手绘和处理参数
