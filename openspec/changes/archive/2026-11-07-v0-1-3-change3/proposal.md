# Proposal（提案）

## Why（为什么）

Change 2 只能生成不可修改的黑白基础稿，纯色去底后的残留边缘也无法清理；用户还不能把系统生成的印稿修整成最终可用的篆刻稿。Change 3 需要补齐 P2 的手动编辑、阴阳刻、镜像、边框和完整恢复能力，为后续作品列表、预览和导出提供稳定的最终黑白稿状态。

## What Changes（变更内容）

- 在 P2 增加“05 黑白稿编辑”：黑色画笔、橡皮、撤销、重做、放大和线宽调整。
- 在 P2 增加“06 阴 / 阳刻与边框”：阳刻/阴刻、正常/左右镜像，以及无、单线、粗线、双线、残破边五种边框。
- 手工编辑发生在 Change 2 自动生成的黑白基础稿之上，编辑结果仍是纯黑纯白像素。
- 手动修整使用独立的可持久化覆盖层；撤销/重做历史只在当前编辑会话中保留，不写入 localStorage。
- 将作品数据从 v2 升级到 v3，保存手动编辑覆盖层、生成签名、画笔尺寸、阴阳刻、镜像和边框设置，并迁移 v1/v2 数据。
- 扩展 P2 自动保存和恢复：画笔/橡皮笔画结束后保存，设置变化延迟保存，重新打开作品时恢复手动修整及印章设置。
- 在 P2 顶部保留“草稿”和“保存（已完成）”；增加不执行跳转的“A4 导出”占位按钮，实际导出能力留待后续 Change。
- 保持 Change 2 的输入、纯色去底、外形尺寸和自动适配能力；修改 01–04 处理参数时，若已有手动修整则明确提示并重置修整覆盖层。

## Capabilities（能力）

### New Capabilities（新增能力）

- `editor-binary-editing`：P2 黑白稿手动修整、撤销重做、局部放大、线宽、阴阳刻、左右镜像、系统边框、纯黑白输出和本地恢复。

### Modified Capabilities（修改能力）

无。

## Impact（影响）

- 影响 P2 的编辑工作区、黑白稿画布、左侧 05–06 工具区和顶部操作区。
- 新增黑白编辑覆盖层、笔画栅格化、历史记录、视图缩放、阴阳刻、镜像和边框渲染模块。
- `WorkRecord` 增加黑白编辑状态；localStorage 从 v2 升级到 v3，并保留 v1/v2 用户、作品、图片状态和活动账号。
- 手动编辑覆盖层需要压缩存储；保存失败时保留内存画布并允许重试。
- 不新增 API、服务端、数据库、外部 AI、P3 作品列表、P4 A4 排版或 PDF 导出。
- 不包含自动可刻性检查、移动端布局、红印预览或真实打印/雕刻结果验证。
