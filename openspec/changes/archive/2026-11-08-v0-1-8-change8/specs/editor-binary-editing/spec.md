# Spec Delta

## ADDED Requirements

### Requirement: 新系统边框

P2 必须（MUST）提供无、单线、双线三种新边框，不得提供粗线或残破边；边框适配方形、长方形和圆形印章，并提供 1–8 级边框粗细和 0–20 mm 边框外边距。

#### Scenario: 选择边框

- **WHEN** 用户查看阴/阳刻与边框模块
- **THEN** 只出现无边框、单线和双线，不出现粗线或残破边

#### Scenario: 圆形边框

- **WHEN** 用户为圆形印章选择边框
- **THEN** 边框沿圆形边界显示，不出现在圆形范围外的白色角落

#### Scenario: 调整边框粗细

- **WHEN** 用户拖动边框粗细滑杆
- **THEN** 当前边框线宽按 1–8 级设置实时变化

#### Scenario: 调整边框外边距

- **WHEN** 用户拖动边框外边距滑杆
- **THEN** 边框与画布外边缘之间的距离按 0.1 mm 步进实时变化

#### Scenario: 无边框时禁用控件

- **WHEN** 用户选择“无边框”
- **THEN** 边框粗细和边框外边距控件禁用

## MODIFIED Requirements

### Requirement: P2 黑白稿编辑入口

P2 必须（MUST）始终允许在“图片编辑”和“黑白稿编辑”之间双向切换，不以是否存在黑白基础稿作为切换条件。没有基础稿时仍显示工具区和空画布说明，但依赖基础稿的画笔、橡皮、撤销重做和预览操作禁用；基础稿只来自当前作品的上传图片。

#### Scenario: 有基础稿时进入编辑

- **WHEN** 用户已上传图片且系统生成了黑白基础稿
- **THEN** 用户可以进入“黑白稿编辑”模式并使用可用工具

#### Scenario: 无基础稿时禁用编辑

- **WHEN** 用户尚未提供图片
- **THEN** 用户可以进入“黑白稿编辑”查看空画布和工具说明，但画笔、橡皮等编辑操作保持禁用

#### Scenario: 任意时刻返回图片编辑

- **WHEN** 用户处于黑白稿编辑模式，无论是否已有基础稿或手动修整
- **THEN** 用户都可以立即切回图片编辑，状态不被重置

## REMOVED Requirements

### Requirement: 系统边框

**Reason**：Change 8 不再读取历史边框数据，旧系统边框要求包含残破边兼容和粗线迁移口径。

**Migration**：改用新的“新系统边框”要求；旧 v7 数据直接清空。

### Requirement: 历史残破边兼容

**Reason**：旧作品不需要迁移，历史残破边不再需要恢复、预览或导出。

**Migration**：旧本地数据清空后，应用只提供无、单线、双线边框。

### Requirement: 历史粗线迁移

**Reason**：旧粗线作品不再迁移或恢复。

**Migration**：删除旧数据读取与粗线换算逻辑，新作品只使用无、单线、双线边框。
