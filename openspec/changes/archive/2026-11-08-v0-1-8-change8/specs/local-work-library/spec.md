# Spec Delta

## Purpose

定义无需账号的单一浏览器本地作品库，负责作品的创建、保存、恢复、删除、localStorage v8 数据边界和旧版本数据处理。

## ADDED Requirements

### Requirement: 单用户本地作品库

应用必须（MUST）把当前浏览器中的一个 localStorage 数据区作为唯一作品库；库内作品没有用户标识、所有者或可见范围差异。

#### Scenario: 查看全部本地作品

- **WHEN** 用户进入作品列表
- **THEN** 系统展示当前浏览器作品库中的全部作品，不按账号或所有者过滤

#### Scenario: 不同浏览器相互独立

- **WHEN** 用户分别在两个浏览器配置中打开同一网址
- **THEN** 每个浏览器只显示自己 localStorage 中的作品

### Requirement: localStorage v8 结构

当前持久化根状态必须（MUST）为 `version: 8` 和作品数组；不得包含 `users`、`activeUserId`、手机号或 `ownerId`。

#### Scenario: 初始化空作品库

- **WHEN** 浏览器中没有应用数据
- **THEN** 系统创建空的 v8 本地作品库，不创建用户或活动账号

#### Scenario: 保存新作品

- **WHEN** 用户保存一件新作品
- **THEN** localStorage 中只增加该作品本身，不写入任何账号或所有者字段

### Requirement: 旧版本数据清空

系统必须（MUST）允许不迁移 v1–v7 的旧账号和旧作品数据；检测到旧版本数据时，可以清空并以空 v8 作品库启动。

#### Scenario: 检测到旧版本

- **WHEN** 启动时读取到 v1–v7 数据
- **THEN** 系统清除旧应用数据、初始化空 v8 作品库并显示一次旧数据已重置提示

#### Scenario: 页面不崩溃

- **WHEN** 旧数据被清空或无法读取
- **THEN** 应用仍进入可用的创作编辑页，用户可以从空白作品开始

### Requirement: 创建并命名作品

用户必须（MUST）能够直接创建新作品、编辑名称，并以草稿状态保存；创建过程不得要求登录或账号上下文。

#### Scenario: 创建新作品

- **WHEN** 用户输入有效名称并保存新作品
- **THEN** 系统在本地作品库中创建该作品，状态默认为草稿并更新最后保存时间

#### Scenario: 名称为空

- **WHEN** 用户尝试保存名称为空的作品
- **THEN** 系统阻止保存并提示需要填写作品名称

### Requirement: 保存草稿与已完成状态

本地作品必须（MUST）支持草稿和已完成两种状态；点击“草稿”保存为草稿，点击“保存”保存为已完成。

#### Scenario: 保存草稿

- **WHEN** 用户点击“草稿”且作品有效
- **THEN** 作品名称、状态、编辑数据和最后保存时间写入 localStorage

#### Scenario: 保存已完成

- **WHEN** 用户点击“保存”且作品有效
- **THEN** 作品状态更新为已完成并写入最后保存时间

### Requirement: 同一浏览器恢复作品

系统必须（MUST）允许用户在同一浏览器中重新打开本地作品，并恢复最后保存的名称、状态和编辑状态，无需再次选择账号。

#### Scenario: 刷新后恢复

- **WHEN** 用户保存作品后刷新或重新打开同一网址
- **THEN** 作品列表仍显示该作品，打开后恢复最后保存内容

#### Scenario: 清除站点数据

- **WHEN** 用户清除当前站点的浏览器数据
- **THEN** 本地作品库不可恢复，系统下次启动为空白

### Requirement: 本地自动保存

有效作品的名称、编辑参数和状态变更必须（MUST）在自动保存延迟后写入当前浏览器 localStorage；空白作品不得创建或覆盖作品记录。

#### Scenario: 自动保存有效修改

- **WHEN** 有效作品发生自动保存范围内的修改并停止操作超过延迟
- **THEN** 最新作品数据写入 localStorage

#### Scenario: 空白作品不写入

- **WHEN** 新建作品没有可打印内容时发生名称或参数变化
- **THEN** 系统不创建空白作品记录

### Requirement: 永久删除本地作品

作品列表必须（MUST）允许删除当前浏览器作品库中的作品；确认后从 localStorage 永久移除，不提供恢复。

#### Scenario: 删除作品

- **WHEN** 用户在二次确认中确认删除已选作品
- **THEN** 所选作品从本地作品库永久移除

#### Scenario: 删除未知标识

- **WHEN** 删除请求包含本地作品库中不存在的标识
- **THEN** 系统忽略该标识并保持现有作品不变
