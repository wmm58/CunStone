# Spec Delta

## MODIFIED Requirements

### Requirement: P2 保存结果弹窗

点击“草稿”或“保存”成功后，系统必须（MUST）使用弹窗说明保存结果和本地数据范围，不再把这些信息常驻在页面上。

#### Scenario: 草稿保存成功

- **WHEN** 用户点击“草稿”且保存成功
- **THEN** 系统显示标题“草稿已保存”和正文“作品已保存到当前浏览器。清除站点数据或更换设备后可能无法恢复。”

#### Scenario: 已完成保存成功

- **WHEN** 用户点击“保存”且保存成功
- **THEN** 系统显示标题“作品已保存”和正文“作品已保存到当前浏览器，可继续编辑，也可在作品列表中预览或进入 A4 排版。”

#### Scenario: 关闭保存结果弹窗

- **WHEN** 用户关闭保存结果弹窗
- **THEN** 页面继续停留在当前作品编辑状态，不常驻显示草稿、未保存、账号或权限说明

### Requirement: P2 未保存内容处理

P2 存在未保存修改时，用户点击“作品列表”或其他内部离开动作前，系统必须（MUST）弹出未保存处理弹窗，提供“继续编辑”“保存草稿并继续”“直接离开”。

#### Scenario: 保存草稿后离开

- **WHEN** 未保存弹窗中用户选择“保存草稿并继续”且保存成功
- **THEN** 系统保存草稿并完成原离开动作

#### Scenario: 直接离开

- **WHEN** 用户选择“直接离开”
- **THEN** 系统放弃本次未保存修改并完成原离开动作

#### Scenario: 保存失败阻止离开

- **WHEN** 用户选择“保存草稿并继续”但保存失败
- **THEN** 系统停留在 P2、保留当前内容并显示失败提示

#### Scenario: 继续编辑

- **WHEN** 用户选择“继续编辑”
- **THEN** 系统关闭弹窗，不离开当前页面

## REMOVED Requirements

### Requirement: 既有本地作品状态迁移

**Reason**：Change 8 不要求保留 v1–v7 的账号或旧作品数据，允许以空的单用户作品库启动。

**Migration**：检测到旧版本数据时直接清空，并初始化 localStorage v8 空作品库；不读取、不转换、不恢复旧作品。
